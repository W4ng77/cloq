## 2. 已确立的数字（4B，τ² retail+airline 85 dev 任务，greedy，确定性 serving）
- BF16 pooled 0.376 / long 0.297；RTN 0.271 / 0.108（= 18 个 GPTQ ckpt 的最小值）。
- arm 置换 p=0.683 pooled / 0.368 long；draw-seed 置换 p=0.881 / 0.744。
- v0 +0.121：精确 McNemar p=0.0195（one-sided），v1 复验 −0.035。
- 开环 NLL/token：Static 0.094、其余 5 arm 0.076、RTN 0.157；NLL 与闭环成功 |r| ≤ 0.13（两种汇总口径符号相反，论文需固定一种）。
- 翻转由状态决定：BF16 NLL 预测开环翻转 AUC 0.93，同 arm/跨 arm 翻转相关 0.548/0.538。
- 失败以写操作为主，arm × 失败类别 p=0.94。
- 循环归因（150 条提前终止）：agent 侧 37%、无重复 35%、混合 20%、simulator 侧 8%；剔除 simulator 侧后单 ckpt 成功率变动 ≤ 0.009。

## 4. 论文方向（已与用户确认）
COLING 长文，主线"扰动等价"：闭环里任何足够大的扰动都会让轨迹 re-roll，压缩是否有损要用模型自身扰动分布衡量；一阶 margin 模型给出三个可证伪预测（偏离饱和、损伤阈值更晚、跨模型可由 margin 分布预测），在 6 个模型上检验。详见 docs/A6000_PLAN.md 与 docs/COLING_PLAN.md。
