## 2. 提议的新主线（请拍板）

**核心认识（候选）**
> 在闭环智能体中，量化引起的局部动作差异，其任务后果与同精度的扰动无法区分。在分歧点回退到 BF16，与换成另一个同精度模型的动作或执行，产生同样多的救回、损害和控制器依赖。没有同精度基线的"量化 vs BF16"后果比较，会把系统的通用敏感性误判为精度效应。

**三个发现（拟）**
1. **闭环把局部差异放大成双向结局翻转。** 约 17% 的任务×block 单位翻转，在 τ²、BFCL、ALFWorld 和 telecom 都出现；效应随后续控制器改变，约四分之一状态如此。
2. **这种放大不是精度特有的。** 同精度替换产生相同的 M、off-diagonal 和净收益（本次结果，§1）。
3. **找到敏感决策 ≠ 找到有益替换。** 现有触发规则能富集翻转，但没有净收益；oracle 有空间。在新框架下更自然的读法是：既然后果主要来自通用敏感性，就不应期待"精度信号"能挑出有益替换。

**贡献（拟）**
1. 同状态交叉干预加同精度对照的评估协议：能把精度效应与闭环敏感性分开，可审计、可重放。
2. 系统实证：双向翻转与控制器依赖普遍存在，但与精度无关。另有家族内规模（q14）、预注册 telecom 留出集、外部环境的检查。

**标题候选**
- *Is It the Precision? Same-State Interventions Separate Quantization Effects from Closed-Loop Sensitivity in LLM Agents*
- *Local Precision Changes in Agents Act Like Any Perturbation: Evaluating Quantized Agents with Same-State Interventions*

**不变的部分**
- 预注册留出集的判读：主终点 −4.6 pp [−7.2, −2.0]，按冻结规则为 inconclusive；S1、S2 通过。
- 外部环境、q14、Bank U、token 规则的结果本身。
- 只是读法从"精度的价值"改为"敏感性的规律与精度的特异性"。
