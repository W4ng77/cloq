## 8. Caveats

- INTERIM. Phase 2 (f04–f06) will add up to 3 blocks per cell. The final protocol analysis (`analyze_newmethod.py --model m24`, all admitted blocks) supersedes every number here. Nothing here was used to make any decision.
- G−H (= Y_BQ − Y_QB) is not a §4 estimand of this protocol. It is added for the paper's question, with the same Boot, seed and ratio form as G/H/F. Per-block values, the M1 point estimates and the q8 83-task view are also additions. Every protocol field is recomputed and asserted equal to the protocol runs' JSON.
- The available-rows sensitivity drops the errored states (Mistral parse errors), so it is not missing-at-random. It also adds airline:13 outside the A3 population. The complete-case analysis keeps the population but mixes blocks of different completeness.
- m24 estimates describe the 83-task conditional population (A3.2). The q8 reference states lie on q8's own BF16 trajectory, so the states differ even where the tasks are equal. The comparison is descriptive and nothing is pooled.
- BFCL states are each cell's own first divergences on the same items. Cross-cell BFCL contrasts compare items, not states.
- Local fidelity (§9; KLu, exact-agreement strata, KL tertiles) is pending, because the m24 score outputs on disk are the failed pre-fix runs.
