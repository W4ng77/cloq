## Method

```
EXPLORATORY, POST HOC (review 2026-10-04): which intervention changes the outcome at a divergent state.
Arms XY: X = source of the action at the divergent state, Y = continuation controller (method.tex: Delta_Q = Y_BQ - Y_QQ, Delta_B = Y_BB - Y_QB).
Per state: act_any = 1[Y_BQ != Y_QQ or Y_BB != Y_QB] (changing the action changes the outcome under at least one continuation controller);
cont_any = 1[Y_BB != Y_BQ or Y_QB != Y_QQ] (changing the continuation controller changes it under at least one action); act - cont per state.
Five classes partition the 16 patterns: unchanged (k = 0 or 4), action only (1100, 0011), continuation only (1010, 0101), one arm differs from
the other three (k odd), strict reversal (1001, 0110). Identities: act_any = odd + action only + reversal; cont_any = odd + continuation only + reversal.
A k-odd state changes under both interventions, so act_any and cont_any overlap; neither share alone says whether a deep interaction exists.
Estimation exactly as offdiag_null.group: ratios of sums per cell, pools = equal-weight mean of cell ratios on common blocks, block bootstrap
(t over per-block ratios if K < 10) and task-cluster bootstrap, B = 2000, seed 20261001; BFCL/ALFWorld: stratified item bootstrap.
Same inputs and loaders as offdiag_null (analysis/fork/holdout/ is never opened; holdout rows: point estimates from stored 16-pattern counts).
usage: python analysis/fork/outcome_classes.py [--B 2000] [--selftest] -> analysis/fork/out/outcome_classes_<UTC>.{md,json}
```
