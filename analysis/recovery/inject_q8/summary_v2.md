## Definitions

- **rescue/damage (A vs ref)**: rescue = Y(A)=1 & Y(ref)=0; damage = Y(A)=0 & Y(ref)=1; turnover = rescue + damage; net = mean Y(A)-Y(ref)
- **D_INV**: [Y(INV,B)-Y(VAL,B)] - [Y(INV,Q)-Y(VAL,Q)]
- **D_PP**: same with PP in place of INV
- **error_specific_effect**: Y(INV,c) - Y(PP,c) per state: the injection's effect beyond a generic process perturbation
- **excess_turnover_INV_minus_PP**: 1[Y(INV,c) != Y(VAL,c)] - 1[Y(PP,c) != Y(VAL,c)] per state
- **manipulation**: wrong_id: injected call reproduced and the tool returned an error / not-found; wrong_tool: the intended wrong tool was called and executed (its result recorded); premature_write: the write executed and changed the DB; VAL: the recorded read executed without error/defect flags (premature_write: a text confirmation request); PP: repeated read without error and no DB change
- **event chain**: error occurred (manipulation ok) -> correction (wrong_id: the same tool later called without error and without the bad id; wrong_tool: the valid tool later called without error; premature_write: a user objection followed by a later write) -> related requirement satisfied (wrong_id/wrong_tool: all gold action checks on the valid tool matched, n/a if the gold has none; premature_write: end DB equals gold on every path the injected write changed)
- **process cost**: extra_steps = final steps - steps used at t; budget_used_frac = extra_steps / steps left at t; tool_errors = final errors - errors at t; agent_turns and completion tokens over the branch decisions
