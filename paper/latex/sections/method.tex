\section{Crossed Same-State Intervention}
\label{sec:method}

\subsection{Setting}
\label{sec:setting}

\paragraph{Tasks and agents.} We use \tautwo{} in text mode. The development panel has 58 retail and 27 airline tasks plus 80 telecom development tasks. A further 34 telecom tasks form a holdout that no agent ran before its protocol was frozen. % src: manifests/fork/splits_v1.json
The agents are Qwen3-4B-Instruct (q4) and Qwen3-8B with thinking disabled (q8). The user simulator is one greedy Qwen3-30B-A3B-Instruct model shared by all agents. % src: /data/ziyangs/cloq_work/sims/*.json (hf_id); docs/RESEARCH_LOG.md (stale user_model_id field); docs/FINAL_EXPERIMENTS.md
Retail and airline success is the final-database match; telecom uses the official task-basis success. Without a user simulator, we also run BFCL multi-turn and ALFWorld, once per item (Appendix~\ref{app:setup}).

\paragraph{Quantization and serving.} Q is a simulated (fake-quantized) checkpoint served with BF16 compute on the same path as B. The main cells are GPTQ \citep{frantar2023gptq} and AWQ \citep{lin2024awq} at W4 and a KV8 cache; stress cells are GPTQ-W3, RTN-W3 and a Q/K-rotated KV4 cache. B and Q run on vLLM with batch-invariant kernels and deterministic compilation, in separate server processes, so no prefix cache is shared across weights. A \emph{block} is one closed-loop run of Q over the task pool under one prompt nonce, a random session-identifier line in the system prompt. Nonce blocks are the replicate unit.

\subsection{Frozen states and estimands}
\label{sec:estimands}

\paragraph{Frozen state.} Before Q's decision $t$ in a recorded trajectory, we restore the state $s_t$. It comprises the full message history; the environment and user-device databases, rebuilt by strict replay of every recorded tool call; the user simulator's visible conversation; and the used step and error budget. B and Q each generate a full action from the same request, and the prompt token ids both servers receive must be identical. The state is written to disk before any branch runs.

\paragraph{Crossed intervention.} $\YY{XY}\in\{0,1\}$ is task success when the action at $s_t$ comes from X and controller Y takes over from the next step to the end, with X, Y $\in\{\mathrm{B},\mathrm{Q}\}$. The action is executed by the real environment or answered by the real simulator and consumes one step; all four branches start from the same frozen state with the original remaining budget. Each escalation option is a paired contrast with QQ: % nocheck: notation {0,1}
\begin{align*}
G &= \YY{BQ}-\YY{QQ} && \text{(this step only)},\\
H &= \YY{QB}-\YY{QQ} && \text{(from the next step)},\\
F &= \YY{BB}-\YY{QQ} && \text{(from here on)}.
\end{align*}
Their paired differences compare the options directly: $G-H=\YY{BQ}-\YY{QB}$, $F-G=\YY{BB}-\YY{BQ}$ and $F-H=\YY{BB}-\YY{QB}$. The effect of swapping the action can be read under either controller: $\DQ=\YY{BQ}-\YY{QQ}$ (Q continues; equal to $G$) and $\DB=\YY{BB}-\YY{QB}$ (B continues). Each takes values in $\{-1,0,+1\}$, which gives a $3\times3$ table per state population. On its diagonal, the action swap has the same effect under both controllers. Off the diagonal, the interaction $I=\DQ-\DB$ is nonzero. The two corners $(+1,-1)$ and $(-1,+1)$ are \emph{strict reversals}: the better action under one controller is the worse one under the other. The contrasts measure effects on task success, not which action is correct. % nocheck: notation {-1,0,+1}, 3x3, corners

\paragraph{Rescue and damage.} For the current-action swap, a \emph{rescue} is $(\YY{BQ},\YY{QQ})=(1,0)$ and a \emph{damage} is $(0,1)$. With rates $r$ and $d$, the outcome turnover is $M=r+d$ and the net gain is $r-d$. % nocheck: notation (1,0), (0,1)

\subsection{Replay acceptance}
\label{sec:replay}

Causal reading requires exact replay. Before any development outcome was analysed, an engineering gate on real divergence states in retail, airline and telecom passed every check; one B$\rightarrow$B field, the official reward, was missing from older trajectories and was recomputed from the stored reward information before the verdict. Q$\rightarrow$Q no-ops matched in 20/20 states and B$\rightarrow$B no-ops in 10/10, in every prompt-token hash, message, database hash, termination, reward and budget counter. % src: docs/insights/FORK_PROTOCOL.md §8 (analysis/fork/gate/)
In production, every fork task re-ran the QQ no-op on a 10\% sample of its states, selected by a hash of the state identifier and therefore independent of outcomes; a single mismatch would have quarantined the task's whole output. % src: docs/insights/FORK_PROTOCOL.md §9 (QQ no-op on a 10% hash sample; stop rule); scripts/a6000/fork_driver.py (noop_frac)
All 924 sampled states of the development analysis passed, as did 328/328 sampled Bank U states; the Bank U gate passed a further 135/135 no-ops. % src: analysis/fork/out/dev_all_20261001T070326Z.md; analysis/fork/bank_u/*/f0*/bank_summary.json (noop); analysis/fork/bank_u/gate/*/f01/bank_summary.json; derived: 328=18+13+15+31+14+20+16+24+19+16+17+19+25+17+16+15+18+15
Serving closes the prefix-cache channel \citep{patodiya2026same}.

\subsection{State banks}
\label{sec:banks}

\paragraph{Bank P: first tool-structure divergences.} For each task, block and quantized cell, we walk along Q's trajectory to the first decision at which $a_{\mathrm{B}}$ and $a_{\mathrm{Q}}$ differ in kind (tool call, text, stop), tool name, call count or order, or normalised arguments. \textbf{Differences in text only are skipped}: two different natural-language replies, or identical calls with different accompanying text, are not Bank P states, and the walk continues past them.

\paragraph{Bank U: ordinary states.} Bank U draws one decision per task uniformly, with the draw fixed by a hash, in three nonce blocks (f01--f03); its manifest was frozen before any generation. It includes \emph{all} full language actions: every state runs all four branches unless $a_{\mathrm{B}}$ and $a_{\mathrm{Q}}$ are token-identical, and no effect is imputed. U1 states come from each quantized cell's own trajectories. U2B (BF16 trajectories) and U2Q (Q trajectories) give every cell of a model the identical state (a common-controller check is in Appendix~\ref{app:banku}). % src: analysis/fork/out/bank_u_f01_f02_f03_20261002T003037Z.md (§1, §2); docs/insights/FORK_PROTOCOL.md §15 amendment 1

\subsection{Denominators and inference}
\label{sec:inference}

We use three denominators and never mix them. (1)~\emph{Full pool}: every task $\times$ block unit of a cell, with units that have no Bank P state counted as zero. $r$, $d$, $M$ and the net gain $\Gall=r-d$ use it (\S\ref{sec:r1}). (2)~\emph{Divergent states}: the Bank P states of one cell, as a ratio of block sums. $G$, $H$, $F$ and the $3\times3$ table use it (\S\ref{sec:r2}); $\Gall$ is $G$ diluted by the share of units without divergence. (3)~\emph{Bank U}: one state per task, task-equal, per sub-bank (\S\ref{sec:r3}). % nocheck: list labels (1)-(3), 3x3

All tasks of a block share its nonce, and all branches share each state. Every within-cell contrast is therefore paired and \emph{identified} for that cell's state population. Comparisons across cells (q4 vs.\ q8, AWQ vs.\ GPTQ, W4 vs.\ KV8) compare different state populations, because each cell selects its own first divergences, so they are \emph{descriptive}. Only complete blocks enter; a block with any missing unit leaves the analysis. The primary interval treats the task pool as fixed: a block bootstrap with at least 10 complete blocks, otherwise a $t$ interval over block means. Stress cells have 3 blocks, so their $t$ intervals rest on two degrees of freedom and can be wider than the crossed intervals. A crossed task $\times$ block bootstrap is the interval for generalising to new tasks. % src: analysis/fork/out/ghf_20261001T211519Z.md (Intervals: stress cells have 3 blocks)
Bank U intervals are $t$ over its three block means. % src: analysis/fork/out/bank_u_f01_f02_f03_20261002T003037Z.md
