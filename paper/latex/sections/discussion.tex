\section{Discussion}
\label{sec:discussion}

\paragraph{Sensitivity, upgrade value and the extra value of precision are separate questions.} How often a local replacement changes the outcome, how much net value a specific upgrade mode brings, and how much more a higher-precision replacement provides than a same-precision one need separate measurements. Replacing one action changes outcomes in both directions: many, for little net value, at Qwen3's first tool-structure divergences, and about 10\%, with no resolved net value, at Mistral's ordinary BF16-sourced states (\S\ref{sec:value}, \S\ref{sec:scope}). The action and the continuation both change outcomes, on overlapping sets of states, and on the fixed task pool paired comparisons separate the upgrade modes in some cells but not in the W4 pool. These are operational consequences of specific upgrade modes, not by themselves evidence of a distinct interaction mechanism (Appendix~\ref{app:offdiag}). % src: analysis/insights/iter_4/out/success_ni_ALIGNED_20260930T213009Z.md; analysis/fork/out/outcome_classes_20261004T143614Z.md; analysis/fork/out/newmethod_m24_20261004T024453Z.md

\paragraph{Changing outcomes is not improving them.} A second checkpoint at the same bit width, at W4 and at W3, changes outcomes about as often as B does, on a shared core of units plus many that only one substitution affects (\S\ref{sec:sameprec}); a flip shows only that the outcome at that state is sensitive to the action, not that it needs more bits. On identical states, B's action is shown neither worth more than the second checkpoint's nor equivalent to it, and a signal that finds flips does not yet find net gains (\S\ref{sec:r4}). We do not conclude that precision is irrelevant: neither reference shows equivalent turnovers, and B's single-cell values stand. % src: analysis/fork/out/sameprec_20261004T070601Z.md (Amendment A1); analysis/fork/out/commonstate_20261002T201612Z.md; analysis/fork/out/sameprec_w3_20261004T070607Z.md (Amendment A1)

\paragraph{Recommendations for evaluating precision interventions in agents.} (i)~Report the rescues and damages of the specific upgrade mode (the action, the continuation, or both) on the same states, not only success rates or flip rates. (ii)~Include a same-precision reference substitution, so that sensitivity is not read as a need for precision. (iii)~Give intervals for both the fixed task pool and new tasks (crossed), because the conclusions can differ, as for the W4 $G-H$ family (\S\ref{sec:value}). % nocheck: list labels (i)-(iii)
