The study changes how a fallback result should be interpreted. A disagreement identifies a place where models behave differently. A flip identifies a place where substitution changes the task. Neither determines whether higher precision improves that task. The reference experiments separate these questions, and the signed benefit measures the last one.

\paragraph{A reference model is not an oracle.} BF16 is the full-precision version of the tested model, not a guaranteed better policy. Qwen3-4B GPTQ-W4 reaches 40.0\% end-to-end DB success versus BF16's 35.8\% (Appendix~\ref{app:e2e}). Even a model with a better overall score can have unhelpful actions at particular histories. Inserting those actions also creates trajectories neither model would have generated alone. This explains why a complete-model comparison cannot determine the value of a local fallback; it does not explain the cause of the negative telecom estimate.

The selected RTN-W3 example gives the complementary case (Table~\ref{tab:scope}). A degraded agent has a positive takeover estimate even though replacing only the current action is unhelpful. The protocol can therefore measure substantial task benefit where it appears. This exploratory example was chosen from five stress settings; it does not establish a general bit-width threshold for useful fallback. BFCL and ALFWorld extend the measurements to environments without an LLM user, and Mistral adds a second model family. Their populations and paired estimates are given in Appendix~\ref{app:scope}.

\paragraph{Target the executed upgrade.} Borrowing one action asks Q to use it. Handing over the task asks B to handle later decisions. A selector trained on joint-takeover outcomes can therefore rank states differently from one targeting action-only replacement. Figure~\ref{fig:rd}c shows why similar average estimates do not make the labels interchangeable: a rescue under one mode may fail under another.

The selection objective must also retain the sign of the consequence. Turnover gives a rescue and a damage the same positive weight; task benefit gives them opposite signs. Our margin rule illustrates the difference on the same selected decisions. The hindsight oracle establishes an upper bound available after observing the labels, not the ability of Q-visible features to predict them. A learned selector should be tested on held-out decisions against a baseline spending the same fallback budget. For comparisons across modes, that budget should match BF16 computation, because a takeover may use many more decisions than a single borrowed action. We do not measure costs.

\paragraph{From a controlled comparison to expected benefit.} Our paired branches measure realised task consequences under fixed execution conditions. Exact replay verifies that the baseline is preserved; it does not make individual rescue and damage labels invariant to other conditions. Key reordering shows that the representation subsequently read by an agent can matter even when the tool operation is unchanged. The shared-state comparison is a separate test of BF16's additional value, and its intervals still allow a useful advantage.

For an expected deployment benefit, the next step is to specify the prompt and user conditions over which the policy should work. Repeat paired branches across that distribution, then average their success differences. This addresses expected gain; repeated labels can separately assess whether the same decisions remain rescues or damages. Our intervals account for task and prompt-block sampling, while the current branches use one greedy user simulator and a dense-BF16 serving path. They do not cover changes to the user model or serving kernel. The telecom holdout already shows why new tasks need a direct test: action-only fallback has a negative estimate there. Domain and tasks changed together, so the cause remains unidentified.

\section{Conclusion}
\label{sec:conclusion}

A precision fallback is valuable when it saves more tasks than it spoils. Our paired branches measure that benefit separately for action replacement, continuation takeover and joint replacement. The W4 panel shows large changes in both directions and little pooled net gain; the telecom holdout has a negative action-only estimate. Same-precision and unchanged-operation references show why a flip alone cannot diagnose a precision deficit. The frozen selector further demonstrates that locating outcome changes does not establish useful selection. Evaluating a fallback requires its signed task benefit under the continuation that will actually run.
