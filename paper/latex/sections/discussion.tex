\section{Discussion}
\label{sec:discussion}

\paragraph{A precision upgrade has continuation-dependent task value.} The value of replacing one action depends on which model executes the rest of the episode (\S\ref{sec:value}), and the upgrade mode that pays changes with the configuration: the action for Qwen3-14B on BFCL, the continuation in a low-success W3 cell, neither on average over the W4 cells. End-to-end success cannot reveal this, since the four W4 cells' differences can neither be distinguished from zero nor bounded within $\pm$3\pp{}. The rescues and damages of a specific upgrade mode must therefore be measured, on the same states, rather than inferred. % src: analysis/insights/iter_4/out/success_ni_ALIGNED_20260930T213009Z.md

\paragraph{Changing outcomes is not improving them.} A second checkpoint at the same bit width, at W4 and at W3, changes outcomes about as often as B does, on a shared core of units plus many that only one substitution affects (\S\ref{sec:sameprec}); a flip at a state shows that the state is fragile, not that it needs more bits. On identical states, B's action is shown neither worth more than the second checkpoint's nor equivalent to it, and a signal that finds flips does not yet find net gains (\S\ref{sec:r4}). We recommend reporting turnover and continuation dependence next to the net gain with its rescue and damage counts, each with its denominator, for each upgrade mode, and the same quantities for a same-precision substitution beside any claim about precision. We do not conclude that precision is irrelevant: neither reference shows equivalent turnovers, and B's single-cell values stand. % src: analysis/fork/out/sameprec_20261002T142834Z.md (Amendment A1); analysis/fork/out/commonstate_20261002T201612Z.md; analysis/fork/out/sameprec_w3_20261003T023933Z.md (Amendment A1)
