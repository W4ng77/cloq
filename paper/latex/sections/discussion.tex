\section{Discussion}
\label{sec:discussion}

\paragraph{From model change to intervention value.} A single success or flip rate mixes three questions. How often an upgrade changes the outcome is not how much it gains (\S\ref{sec:value}). Which upgrade is evaluated changes which rescues are counted, so action replacement and takeover need separate gain labels. How sensitive the loop is to a change of action is not what higher precision adds (\S\ref{sec:sameprec}). Signals that track divergence or find outcome-changing decisions do not yet find net gains (\S\ref{sec:r4}). We do not conclude that precision is irrelevant: neither reference establishes equivalent turnover, and the resolved fixed-pool cells and the negative holdout estimate (\S\ref{sec:value}) remain. % src: analysis/fork/out/sameprec_20261004T070601Z.md (Amendment A1); analysis/fork/out/commonstate_q8ext_20261003T231159Z.md

\paragraph{Why a fallback cannot be judged by its average gain.} A post hoc decomposition of the \tautwo{} W4 pool explains the small net. Among task$\times$block units where QQ fails (units without a divergent state count as no rescue), B's action rescues 14.6\%; where QQ succeeds, it damages 26.1\%. The totals are similar partly because QQ succeeds in only $34.6\%$ of units, so an average gain hides a rescue rate on failures and a larger damage rate on successes. This decomposition conditions on outcomes, so it cannot guide escalation online. % src: analysis/fork/out/task_fragility_20261005T134836Z.md (Conditional rates, pool)

\paragraph{Recommendations for evaluating precision interventions in agents.} (i)~Specify the intervention (the action, the continuation, or both) and report its rescues, damages and net on the same states. (ii)~Include a same-precision reference, so that sensitivity is not read as a need for precision. (iii)~Report fixed-pool and new-task (crossed) intervals, which can differ (\S\ref{sec:value}). % nocheck: list labels (i)-(iii)
