\section{Discussion}
\label{sec:discussion}

\paragraph{Sensitivity and value are different measurements.} Every analysis here points the same way. Replacing one action turns over many units in both directions for a small net effect, while the end-to-end differences of the four W4 cells can neither be distinguished from zero nor bounded within $\pm$3\pp{} (\S\ref{sec:value}). A second W4 checkpoint produces sensitivity of comparable size, partly on different units (\S\ref{sec:sameprec}), so a flip at a state is evidence that the state is fragile, not that it needs more bits. A signal that finds flips does not yet find net gains (\S\ref{sec:r4}). A decision whose outcome changes easily when the model changes is therefore not thereby worth upgrading; the value of an upgrade must be judged against the complete replaced action, the execution that follows, and a same-precision alternative. In practice we recommend reporting $M$ and continuation dependence as sensitivity, and the net gain with its rescue and harm counts as value, each with its denominator; keeping fixed-pool and new-task intervals apart; and reporting the same quantities for a same-precision reference substitution beside any claim about precision. We do not conclude that precision is irrelevant: the interim reference does not show the two substitutions to be equivalent, and B's measured net values in single cells stand. % src: analysis/insights/iter_4/out/success_ni_ALIGNED_20260930T213009Z.md

\paragraph{What the same-precision reference does and does not settle.} An interaction $I\neq0$ on a deterministic state is a real non-additive effect on the success scale, not replay noise, but by itself it does not establish a quantization-specific mechanism. The reference answers this in part: such interactions arise without a change of bit width. It does not show that B and a second checkpoint are interchangeable; the interim turnover difference is not resolved within $\pm$3\pp{}, and the common-state comparison (\S\ref{sec:sameprec}) is the direct test of what B's action adds. % src: analysis/fork/out/sameprec_20261002T142834Z.md (Amendment A1)
