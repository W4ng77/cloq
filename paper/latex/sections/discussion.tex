\section{Discussion}
\label{sec:discussion}

\paragraph{From model change to intervention value.} The results separate three questions that a single success rate or flip rate mixes. How often an upgrade changes the outcome is not how much it gains: B's action changes many outcomes, in both directions, for a small net, and the consequences recur on the same tasks (\S\ref{sec:value}). Which upgrade is evaluated changes which rescues are counted, so action replacement and whole takeover need separate gain labels. And how sensitive the loop is to a change of action is not what higher precision adds: a second checkpoint at the same bit width changes outcomes about as often, and on common states BF16's additional action value is unresolved (\S\ref{sec:sameprec}). A signal of how much the action changes is not a signal of what the change does, and a signal that finds outcome-changing decisions does not yet find net gains (\S\ref{sec:r4}). We do not conclude that precision is irrelevant: neither reference establishes equivalent turnover, and the cells whose net effect is resolved (\S\ref{sec:value}) remain. % src: analysis/fork/out/sameprec_20261004T070601Z.md (Amendment A1); analysis/fork/out/commonstate_q8ext_20261003T231159Z.md

\paragraph{Why a fallback cannot be judged by its average gain.} A post hoc decomposition of the \tautwo{} W4 pool shows how the small net is composed. Among task$\times$block units where QQ fails (units without a divergent state count as no rescue), replacing the action rescues 14.6\%; among units where QQ succeeds, it damages 26.1\%. The totals are similar partly because QQ fails more often than it succeeds ($P(\text{QQ success})=34.6\%$ of units). An average gain therefore hides a rescue rate on failures and a larger damage rate on successes, and a fallback evaluation has to report both. This decomposition conditions on outcomes known only afterwards, so it cannot be used online to decide when to escalate. % src: analysis/fork/out/task_fragility_20261005T134836Z.md (Conditional rates, pool)

\paragraph{Recommendations for evaluating precision interventions in agents.} (i)~Specify the intervention (the action, the continuation, or both) and report its rescues, damages and net on the same states, not only success or flip rates. (ii)~Include a same-precision reference substitution, so that sensitivity is not read as a need for precision. (iii)~Give intervals for both the fixed task pool and new tasks (crossed), because they can differ (\S\ref{sec:value}). % nocheck: list labels (i)-(iii)
