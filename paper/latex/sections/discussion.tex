\section{Discussion}
\label{sec:discussion}

\paragraph{A precision upgrade has continuation-dependent task value.} The value of replacing one action depends on which model executes the rest of the episode (\S\ref{sec:value}), and paired comparisons distinguish the upgrade modes on the same states: on the fixed task pool, action replacement outperforms continuation takeover in both Qwen3-8B W4 cells, continuation takeover outperforms action replacement in a low-success W3 cell, and the W4 pool shows no detectable difference. Whole-model swap evaluations mix these effects; same-state crossed interventions measure them separately. The rescues and damages of a specific upgrade mode must therefore be measured, on the same states, rather than inferred. % src: analysis/insights/iter_4/out/success_ni_ALIGNED_20260930T213009Z.md

\paragraph{Changing outcomes is not improving them.} A second checkpoint at the same bit width, at W4 and at W3, changes outcomes about as often as B does, on a shared core of units plus many that only one substitution affects (\S\ref{sec:sameprec}); a flip at a state shows that the state is fragile, not that it needs more bits. On identical states, B's action is shown neither worth more than the second checkpoint's nor equivalent to it, and a signal that finds flips does not yet find net gains (\S\ref{sec:r4}). We do not conclude that precision is irrelevant: neither reference shows equivalent turnovers, and B's single-cell values stand. % src: analysis/fork/out/sameprec_20261004T070601Z.md (Amendment A1); analysis/fork/out/commonstate_20261002T201612Z.md; analysis/fork/out/sameprec_w3_20261004T070607Z.md (Amendment A1)

\paragraph{Recommendations for evaluating precision interventions in agents.} (i)~Report the rescues and damages of the specific upgrade mode (the action, the continuation, or both) on the same states, not only success rates or flip rates. (ii)~Include a same-precision reference substitution, so that sensitivity is not read as a need for precision. (iii)~Give intervals for both the fixed task pool and new tasks (crossed), because the conclusions can differ, as for the W4 $G-H$ family (\S\ref{sec:value}). % nocheck: list labels (i)-(iii)
