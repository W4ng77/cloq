\begin{abstract}
Quantization changes some of an LLM agent's actions. In a closed loop, one changed action alters the user's replies, the tool results and every later decision, so end-task success cannot show how such changes become task consequences. We study this with \emph{same-state counterfactual forks}: at the first divergence between a BF16 agent and its quantized counterpart, we replay the identical state and cross \{current action: BF16 or quantized\} $\times$ \{continuation controller: BF16 or quantized\}. Serving is deterministic, so every no-op replay is bit-exact. The four branches give signed estimands: rescues $r$, damages $d$, outcome turnover $M=r+d$, and the gain $G=r-d$ from replacing the action at the forked state, which is not the end-to-end BF16-versus-quantized success difference. On Qwen3-4B and Qwen3-8B in \tautwo{} (85 tasks $\times$ 20 nonce blocks), replacing a W4 agent's divergent action changes the task outcome in 15.5--20.9\% of task-block units, in both directions, while $G$ ranges from $-1.9$ to $+2.9$\pp{}. % src: analysis/fork/out/dev_all_20261001T070326Z.md
Turnover concentrates in fragile tasks whose direction repeats across nonces; this is a retrospective association on development data, and its pre-registered holdout test is pending. On outcome-independent shared states, 39 of the 56 outcome-changing differences are same-structure text differences rather than tool or argument differences. % src: analysis/fork/out/bank_u_f01_20261001T134456Z.md, docs/REPORT_GPT61_20261001_0915.md
