\begin{abstract}
Evaluations of low-precision agents usually measure how far the quantized model drifts from its BF16 reference. A deployment that can fall back to BF16 needs the task value of a specific upgrade under the policy that runs afterwards. We restore a decision state exactly and replace the current action, the subsequent controller, or both with BF16, count the rescues and damages of each option, and compare BF16 with a second checkpoint at the same bit width. On Qwen3 agents under simulated quantization in \tautwo{}, replacing a quantized agent's first divergent action changes many outcomes in both directions for a small net effect; on held-out telecom tasks under a pre-registered protocol, the net effect is $-4.6$ points (crossed 90\% interval [$-7.2$, $-2.0$]). Action-only and whole-takeover evaluations miss different rescues. A second checkpoint at the same bit width produces comparable turnover, so outcome sensitivity is not by itself evidence that more bits are needed. \end{abstract}
