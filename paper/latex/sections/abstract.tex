\begin{abstract}
When a quantized agent and its BF16 reference reach similar average task success, but the quantized agent takes a different action at some state, should BF16 take over, and if so for this one step or from here on? We argue that the answer depends on the state and on the controller that continues, so average success, action divergence and the gain from precision replacement must be measured separately. We propose a crossed same-state intervention: at a frozen, bit-exactly replayable state, we cross the source of the current action (BF16 or quantized) with the controller of the remaining episode. This yields three replacement gains on the same states: the current action only ($G$), the continuation only ($H$), or both ($F$). On Qwen3-4B and Qwen3-8B in \tautwo{} (85 tasks, 20 nonce blocks), replacing a W4 agent's first divergent action changes the task outcome in 15.5--20.9\% of task-block units, in both directions, while the net gain is between $-1.9$ and $+2.9$\pp{}. % src: analysis/fork/out/dev_all_20261001T070326Z.md
In about a quarter of the divergent states that each W4 cell samples (pooled 26.9\%; new-task interval 22.1--32.0\%), the outcome effect of the same action swap changes with the controller that continues. Strict sign reversals are only 1.2--4.2\% of states in the W4 and KV8 cells, and dependence in the two directions is about equally frequent, so the mean interaction is near zero. On the fixed task pool, replacing the current action gains more than replacing the continuation in both q8 W4 cells, and less in a severe W3 stress cell; these contrasts are within cells, and their intervals for new tasks cover zero in the W4 cells. % src: analysis/fork/out/ghf_20261001T211519Z.md
At outcome-independent states, most outcome-changing differences under our user simulator are text differences with the same tool structure. These outcome labels did not reproduce reliably under an alternative, stochastic relay simulator. Quantized-model uncertainty marks where actions diverge; a frozen uncertainty trigger enriches outcome-changing decisions on later blocks but has not been shown to select net-beneficial replacements. % src: analysis/fork/out/bank_u_f01_20261001T134456Z.md; analysis/fork/out/simctrl_20261001T212742Z.md; analysis/fork/out/token_mech_20261001T185031Z.md; analysis/fork/out/token_mech_20261002T003130Z.md
