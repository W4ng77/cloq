\begin{abstract}
When a quantized agent and its BF16 reference reach similar average task success, but the quantized agent takes a different action at some state, should BF16 take over, and if so for this one step or from here on? We argue that the answer depends on the state and on the controller that continues, so average success, action divergence and the gain from precision replacement must be measured separately. We propose a crossed same-state intervention: at a frozen, bit-exactly replayable state, we cross the source of the current action (BF16 or quantized) with the controller of the remaining episode. This yields three replacement gains on the same states: the current action only ($G$), the continuation only ($H$), or both ($F$). On Qwen3-4B and Qwen3-8B in \tautwo{} (85 tasks, 20 nonce blocks), replacing a W4 agent's first divergent action changes the task outcome in 15.5--20.9\% of task-block units, in both directions, while the net gain is between $-1.9$ and $+2.9$\pp{}. % src: analysis/fork/out/dev_all_20261001T070326Z.md
Whether the action swap helps depends on which controller continues in 26.9\% of pooled W4 divergent states. Strict sign reversals are only 1.2--4.2\% of states in the W4 and KV8 cells, and positive and negative dependence cancel, so the mean interaction is near zero. Which replacement pays differs between quantizers, and in a severe W3 cell only the continuation matters. % src: analysis/fork/out/ghf_20261001T211519Z.md
At outcome-independent states, most outcome-changing differences under our user simulator are text differences with the same tool structure. Under a different simulator, however, these text-difference flips are no more frequent than flips at matched non-flip states, so their consequences are largely simulator-dependent. Quantized-model uncertainty marks where actions diverge, but not which divergences have consequences. % src: analysis/fork/out/bank_u_f01_20261001T134456Z.md; analysis/fork/out/simctrl_20261001T212742Z.md; analysis/fork/out/token_mech_20261001T185031Z.md
