\begin{abstract}
A low-precision agent can call BF16 as a fallback. The value of that call depends on the tasks it saves and the tasks it spoils. We measure these consequences by separating replacement of the current action from takeover of later execution, using paired branches from the same restored state. On Qwen3 agents under simulated quantization in \tautwo{}, replacing the first W4 action that differs in tool structure changes 15.5--20.9\% of outcomes. Rescues and damages largely cancel: pooled net gain is $+0.7$\pp{} (new-task 95\% interval [$-2.1$, $+3.4$]). The pre-registered telecom holdout estimate is negative ($-4.6$\pp{}); the protocol classifies it as inconclusive because it omitted a negative-effect category. We test precision attribution with two references: another W4 checkpoint and a tool-argument reordering that preserves the executed operation both change outcomes. At shared states, BF16's extra action value over the second checkpoint remains unresolved; equivalence is not established. A frozen uncertainty trigger finds more outcome-changing decisions than random selection without a reliable net-benefit advantage. Evaluating fallback therefore requires measuring the signed task benefit of the intervention that will run, with references that distinguish precision from other sources of change.
