\begin{abstract}
Evaluations of low-precision agents usually measure drift from BF16. A deployment that can fall back to BF16 needs the task value of a specific upgrade under the policy that continues. We restore a decision state, audit exact replay on sampled states, replace the current action, the continuation, or both with BF16, and count rescues and damages. On Qwen3 agents under simulated quantization in \tautwo{}, replacing a W4 agent's first tool-structure-divergent action with BF16's changes 15.5--20.9\% of outcomes in both directions; the pooled net is $+0.7$ points (95\% interval over new tasks [$-2.1$, $+3.4$]). On held-out telecom tasks, the pre-registered net estimate is $-4.6$ points (90\% interval [$-7.2$, $-2.0$]); the frozen decision rule had no category for a negative effect, so it classifies the result as inconclusive. Two reference interventions also change outcomes: a second same-bit-width checkpoint, whose rescues and damages are both resolved above zero, and reversing tool-argument key order, which leaves the tool operation identical (exploratory). At common states, BF16's extra action value over that checkpoint is not resolved, and equivalence is not shown. Outcome sensitivity is therefore not by itself evidence that an upgrade helps.
