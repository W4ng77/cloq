\begin{abstract}
Outcome flips do not by themselves show that a low-precision agent needs more bits. A fallback is useful only if its rescues outweigh its damages. We measure this signed task benefit by crossing the source of the current action with the model that continues the interaction. On Qwen3 agents under simulated quantization in \tautwo{}, replacing the first tool-structure-divergent W4 action with BF16 changes 15.5--20.9\% of outcomes, yet the pooled net gain is $+0.7$\pp{} (new-task 95\% interval [$-2.1$, $+3.4$]). Action-only fallback can also harm: a pre-registered telecom holdout has a negative estimate of $-4.6$\pp{}; its protocol classifies this as inconclusive because it omitted a negative-effect category. A second W4 checkpoint and a semantically identical tool-argument reordering also change outcomes. At shared states, BF16's additional action value over the second checkpoint remains unresolved; equivalence is not established. A frozen uncertainty trigger enriches outcome-changing decisions without a reliable net benefit over random selection. These findings motivate evaluating the signed benefit of the upgrade actually executed, interpreting flips with reference interventions, and selecting decisions by task benefit rather than sensitivity alone.
