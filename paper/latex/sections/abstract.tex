\begin{abstract}
A quantized agent reaches a decision and its BF16 reference is available. Should BF16 replace only this step, take over the rest of the episode, or both? End-to-end success cannot answer this, and forking a trajectory and continuing it with another model changes the action and the continuation together. We separate them. At a frozen state that replays bit-exactly, a $2\times2$ design crosses the source of the current action with the model that executes the rest of the episode, so the value of each upgrade mode is measured directly on the same state; a second W4 checkpoint of the same model, used in place of BF16, checks which consequences are attributable to precision. % nocheck: design label
On \tautwo{} with Qwen3-4B and Qwen3-8B, replacing a W4 agent's first diverging action with BF16's changes the outcome of 15.5--20.9\% of task--block units, in both directions, for a net effect of $-1.9$ to $+2.9$\pp{}, and in 26.9\% of divergent states the swap's effect depends on which model continues. % src: analysis/fork/out/dev_all_20261001T070326Z.md; analysis/fork/out/ghf_20261001T211519Z.md (§2)
Which mode pays differs by configuration: in a low-success W3 cell the gain comes from BF16 taking over the continuation, while for Qwen3-14B on BFCL it comes from replacing the action. % src: analysis/fork/out/ghf_20261001T211519Z.md (§1); analysis/fork/out/ext_q14_20261002T085647Z.md (§2)
Swapping only the W4 calibration checkpoint also produces two-sided flips and continuation dependence of comparable size; the two substitutions affect a shared core of units plus many units that only one of them changes, and their equivalence is not shown (interim). % src: analysis/fork/out/sameprec_20261002T142834Z.md (Amendment A1); analysis/fork/out/sameprec_overlap_20261002T143218Z.md
A precision upgrade thus has continuation-dependent task value, and the rescues and damages of a specific upgrade mode must be measured rather than inferred from how sensitive a decision is: a frozen uncertainty trigger finds outcome-changing decisions but captures little of the available net gain. % src: analysis/fork/out/token_mech_20261002T003130Z.md (§3); analysis/fork/out/oracle_trigger_20261002T024423Z.md (§1a)
\end{abstract}
