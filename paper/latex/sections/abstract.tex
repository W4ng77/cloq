\begin{abstract}
Evaluations of low-precision agents usually ask how much the model changed. A deployment that keeps a BF16 fallback needs a different quantity: what a specific upgrade is worth under the policy that executes afterwards. An upgrade can replace the current action, the subsequent controller, or both. We present an auditable same-state protocol that measures these interventions separately, counts the rescues and damages each one causes, and compares the BF16 replacement with a same-precision substitute. On Qwen3 agents under simulated quantization in \tautwo{}, replacing a quantized agent's first divergent action changes many task outcomes in both directions with a small net effect on the development panel, and the changes recur on the same tasks under other nonces (exploratory). On held-out telecom tasks under a pre-registered protocol, the net effect is $-4.6$ points (crossed 90\% interval [$-7.2$, $-2.0$]); the pre-registered readings had no negative category and call this inconclusive. % src: analysis/fork/out/holdout_confirm_20261002T012353Z.md
Which upgrade is evaluated changes which rescues are counted: testing only the action misses rescues that need the BF16 continuation as well, and testing only a whole takeover misses action-level rescues that hold under the quantized continuation. A second checkpoint at the same bit width produces comparable turnover, so outcome sensitivity is not by itself evidence that more bits are needed, and when all actions are compared at the same states BF16's extra action value is unresolved. Signals of how much the action changes, such as token KL, track whether the action differs rather than what the difference does to the outcome, and a frozen uncertainty trigger enriches outcome-changing decisions without a reliable net gain. % src: analysis/fork/out/sameprec_20261004T070601Z.md (Amendment A1); analysis/fork/out/commonstate_q8ext_20261003T231159Z.md; analysis/fork/out/kl_decomp_20261005T000559Z.md; analysis/fork/out/oracle_trigger_20261002T024423Z.md (§1a)
\end{abstract}
