\paragraph{Splits.} The development split has 58 retail, 27 airline and 80 telecom tasks. The holdout has 34 telecom tasks, and its pre-registration hash is recorded in the split file. % src: manifests/fork/splits_v1.json
The telecom split was fixed from \tautwo{}'s 114-task base split by a stratified, salted hash before any run. % src: manifests/telecom/dev_v1.json
The external benchmarks use BFCL multi-turn (base, miss\_func, miss\_param and long\_context, 197 items each) and ALFWorld (134 out-of-distribution games). Items were selected by hash in manifests committed before any model run. % src: docs/RESEARCH_LOG.md W36-ext (manifests/bfcl/bfcl_mt_v1.json, manifests/alfworld/alfworld_text_v1.json)

\paragraph{Success endpoints.} For retail and airline we use the final-database match with normal termination. This is not \tautwo{}'s official reward, which additionally scores natural-language or communicate checks. Telecom uses the official deterministic task-basis success. Context overflow and unparseable output count as failures, except for the explicitly amended missing-data rules of the Mistral panel (Appendix~\ref{app:mistral}). Infrastructure outages are missing rather than failures. The primary analysis excludes incomplete blocks; panel-specific exceptions are stated with their estimates.

\paragraph{Fork mechanics.} The forced action is returned by a fork agent for the one step that follows $h_t$. A tool call is executed by the real environment, and text is answered by the real simulator, which never reuses observations from the original trajectory. \tautwo{} resets step and error counters when it starts from a history. The fork restores them to the values used at $t$, so the remaining budget equals the original. Every max\_steps and too\_many\_errors episode on the checked blocks is reproduced by the recount. % src: docs/insights/FORK_PROTOCOL.md §2-§4
\paragraph{Replay acceptance details.} In the engineering gate, one B$\rightarrow$B field, the official reward, was missing from older trajectories and was recomputed from the stored reward information before the verdict. The QQ no-op matched all 924 sampled development states. Ordinary-state checks matched 328/328 sampled states and a separate 135/135 gate set. On the holdout, the initial 135-state sample and the later full replay of all 1202 divergent states matched (Appendix~\ref{app:prereg}). Serving in separate processes closes the prefix-cache channel \citep{patodiya2026same}. % src: docs/insights/FORK_PROTOCOL.md §8 (analysis/fork/gate/); analysis/fork/out/dev_all_20261001T070326Z.md; analysis/fork/bank_u/*/f0*/bank_summary.json (noop); analysis/fork/bank_u/gate/*/f01/bank_summary.json; derived: 328=18+13+15+31+14+20+16+24+19+16+17+19+25+17+16+15+18+15; analysis/fork/out/holdout_qqfull_audit_20261006T061033Z.md (TL;DR); docs/insights/HOLDOUT_QQFULL_PROTOCOL.md (§1-§5, Amendment 1)
The same-precision run's acceptance counts are in Appendix~\ref{app:sameprec}.

\subsection{Internal names and notation}
\label{app:names}

\paragraph{Glossary.} The main text uses plain terms; this supplement also uses the internal names of the analysis code. A \emph{first divergent state} is a \emph{Bank P} state. An \emph{ordinary sampled state} is a \emph{Bank U} state; its sub-banks are drawn from Q's own trajectories (U1) or from trajectories shared by all configurations of a model (U2B: BF16 trajectories; U2Q: Q trajectories). A \emph{common state} is an ordinary state of the common-state design (pre-registered at three blocks, extended to six by amendment), at which B, Q and Q$'$ each supply the current action. A \emph{cell} is a configuration, named by model (q4: Qwen3-4B; q8: Qwen3-8B; q14: Qwen3-14B; m24: Mistral-Small-3.2-24B) and quantization setting. % nocheck: model names
Nonce blocks carry ids such as fNN (development) and qN (stress and W3 panels); the holdout blocks have their own ids. Branches are written by action source and continuing model (BB, BQ, QB, QQ; KQ is the key-order branch, Appendix~\ref{app:keyorder}). Symbols: $r$ and $d$ are the rescue and damage rates of the action swap, $M=r+d$ is the turnover and $\Gall=r-d$ the net gain on the full pool; $\DQ$, $\DB$ and the off-diagonal share are defined below; $I=\DQ-\DB$ is the interaction of action and continuation (Table~\ref{tab:ghf}); $D_{cc}=\YY{QB}-\YY{BB}$ compares methods on shared ordinary states (Appendix~\ref{app:panels}); $K(c)$ is B's action value beyond Q$'$'s at a common state under continuation $c$ (Appendix~\ref{app:commonstate}); $n_{\mathrm{blk}}$ is the number of complete blocks.

\paragraph{Action swap, rescues and damages.} The paired effect of the action swap under each continuation is $\DQ=\YY{BQ}-\YY{QQ}$ ($=G$) and $\DB=\YY{BB}-\YY{QB}$, each in $\{-1,0,+1\}$. When $\DQ\neq\DB$ (``off-diagonal''), the swap's value depends on the continuation. For the action swap, a \emph{rescue} is $(\YY{BQ},\YY{QQ})=(1,0)$ and a \emph{damage} is $(0,1)$; with rates $r$ and $d$, the turnover is $M=r+d$ and the net gain $r-d$. All contrasts measure effects on task success, not which action is correct. % nocheck: notation {-1,0,+1}, (1,0), (0,1)

\paragraph{Same-precision notation.} $M'$, $r'$, $d'$ and the off-diagonal share are defined likewise with Q$'$ for B.

\paragraph{Which states.} \emph{Bank P}: for each task, block and cell, the first decision at which $a_{\mathrm{B}}$ and $a_{\mathrm{Q}}$ differ in kind (tool call, text, stop), tool name, call count or order, or normalised arguments; differences in text only are skipped. \emph{Bank U}: one ordinary decision per task, drawn by a hash fixed before generation, in three nonce blocks (six in the extended q8 common-state design, Appendix~\ref{app:commonstate}), from Q's own trajectories (U1) or from trajectories shared by all cells of a model (U2B: BF16; U2Q: Q). % src: docs/insights/FORK_PROTOCOL.md §15 amendment 1

\paragraph{Denominators and inference.} We keep three denominators separate. (1)~\emph{Full pool}: every task$\times$block unit, units without a Bank P state counting as zero; $r$, $d$, $M$ and $\Gall=r-d$ use it. (2)~\emph{Divergent states}: the Bank P states of a cell; $G$, $H$, $F$ and the off-diagonal share use it. (3)~\emph{Bank U}: one state per task. Within a cell all branches share each state and all tasks of a block share its nonce, so within-cell contrasts are paired and identified; cross-cell comparisons are descriptive, because each cell selects its own divergences. With $n_{\mathrm{blk}}$ complete blocks (only complete blocks enter), the primary \emph{fixed-pool} interval treats the task pool as fixed (block bootstrap if $n_{\mathrm{blk}}\ge10$, else block-$t$, a $t$ interval over block means); the \emph{new-task} interval is a crossed task$\times$block bootstrap (``crossed''). We call a contrast \emph{resolved} under an interval when that interval excludes zero and name the interval; ``not resolved'' means the reported interval or intervals include zero. Where a frozen protocol sets its own reading rule, we state it with the result. % nocheck: list labels (1)-(3)
