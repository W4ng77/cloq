\section{Conclusion}
\label{sec:conclusion}

Under greedy decoding, any perturbation reaching the bf16 grid step re-rolls closed-loop agent trajectories, because free-text turns are full of near-ties; a compiler configuration change, a prompt nonce, 3\% of the RTN-W4 weight error and RTN-W8 reach the same per-decision floor on Qwen3-4B. A single BF16 run is one draw from a distribution, and a compressed agent should be judged against that distribution. On Qwen3-4B, success is not distinguishable from the null up to the RTN-W4 scale and falls only near 3 bits (tentative); whether this holds across sizes, and whether $D$ predicts closed-loop effects, remains open.
