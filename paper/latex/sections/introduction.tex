\section{Introduction}
\label{sec:intro}

Agent benchmarks such as \tautwo{} \citep{barres2025tau2} score a model by letting it interact with a simulated user and a tool environment until the episode ends, and then checking the final database state. When a compressed model is evaluated this way, the usual report is a pair of numbers: the score of the BF16 reference and the score of the compressed model, each from one run. We ask what such a pair can tell us, a question about evaluation methods for agentic systems rather than about any one compression method.

Two observations from our own project are warnings. First, in an early study of calibration data for 4-bit GPTQ on Qwen3-4B, a trajectory-based calibration arm (FP-Traj) beat a static arm by $+0.121$ in database match on 58 retail tasks (8 tasks won by FP-Traj alone, 1 by Static alone; exact one-sided McNemar $p = 0.0195$, two-sided $p = 0.039$); the replication with three independent calibration draws gave $-0.035$ pooled ($-0.045$ on long tasks), with the sign reversed and both intervals spanning zero. Second, and sharper because the model did not change at all: re-serving the same BF16 weights with the same prompt under a different floating-point configuration of the serving stack (for agent and simulator) moved the canonical score of Qwen3-4B from 0.412 to 0.329 and that of Qwen3-8B from 0.316 to 0.380, changing 21 of 85 and 21 of 79 task outcomes. A compressed model compared against either reference run would receive a different verdict.

We explain both observations with one mechanism. Greedy decoding picks the top token at every position. When the top two candidates are nearly tied, any perturbation of the logits that exceeds the gap can flip the choice. This per-step account is established \citep{du2026greedy,chen2026integer,chu2026margingate}. In a closed-loop agent, a flipped token changes the context of every later turn, including the simulated user's replies, so a single flip \emph{re-rolls} the rest of the trajectory. Free-text turns contain many near-ties, so a perturbation of almost any size re-rolls almost every episode. The outcome of each task is then better described as one Bernoulli draw than as a fixed property of the model.

The question ``is the compressed agent worse?'' must then be answered against the outcomes the reference model itself produces under perturbations that carry no capability change: prompt nonces, tiny weight noise, and serving-numerics changes. We make three contributions.

\begin{enumerate}[leftmargin=*,itemsep=1pt,topsep=2pt]
\item \textbf{A criterion.} We define \emph{perturbation equivalence}: a compressed agent is equivalent to its reference if its task-level outcomes are exchangeable with those of a null family built from the reference model's own sub-threshold perturbations. The canonical reference score is one draw from this family (serving numerics alone flip about a quarter of task outcomes; null-draw SDs are consistent with a Bernoulli prediction), so single-draw comparisons can produce false positives such as the one above.
\item \textbf{A closed-loop composition of the per-step margin model, with two measured regimes.} The composition predicts (P1) a per-decision divergence \emph{floor} reached by every perturbation at or above the bf16 grid step, then a regime where the hazard ranks perturbation size; (P2) a \emph{damage} threshold later than the divergence threshold, leaving a zone of full re-rolls with success within the null; and (P3) divergence predictable from the reference margins. P1 holds on Qwen3-4B on clean data and is consistent on Qwen3-8B; P2 is a tentative finding on Qwen3-4B; P3 is partly supported and partly at risk.
\item \textbf{A serving-numerics finding and a deterministic serving recipe.} A compile-time autotuning choice in the fused residual + RMSNorm kernel changed the summation order across nodes, shifted all 113 identical-prompt decisions of a determinism pair (non-zero shifts on 59\% of tokens), and re-rolled about 95\% of its trajectories (Kaplan--Meier estimate over 20 tasks). The fix (deterministic Inductor configuration plus a numerics canary) restores cross-node byte-identity (257/257 and 303/303 decisions).
\end{enumerate}

\noindent An earlier 4B study (Appendix~\ref{app:deepdive}; two RTX 4080 GPUs, 8k harness, the 4B model as its own simulator, numbers recomputed from analysis outputs) adds that 18 GPTQ checkpoints from six calibration strategies are statistically indistinguishable in closed loop (arm-label permutation $p = 0.683$), and that teacher-forced NLL does not track closed-loop success.
