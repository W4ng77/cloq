\section{Introduction}
\label{sec:intro}

A quantized LLM agent is cheaper to serve than its BF16 reference, and a deployment can keep the reference as a fallback, as dynamic precision routing does \citep{li2026dynamicmp}. Suppose the quantized agent (Q) reaches a decision at which the BF16 agent (B) would act differently. There are three ways to spend B here: \textbf{replace only this step, let B take over from the next step, or both}. Average task success does not answer this. On our checkpoints, quantized-minus-BF16 success ranges from $-0.2$ to $+4.2$\pp{} across four W4 cells, and an equivalence test at $\pm$3\pp{} fails in every cell (Appendix~\ref{app:e2e}); even a precise end-to-end number would not say which step an upgrade should touch. % src: analysis/insights/iter_4/out/success_ni_ALIGNED_20260930T213009Z.md

Figure~\ref{fig:case}a shows one such decision from our data. In an airline task, Q looks up a reservation id that does not exist and receives ``not found''; B looks up the user's profile. B's action looks better, and we can check what it is worth. We froze the state and ran all four combinations of \{B's or Q's action\} $\times$ \{B or Q continuing\}. Only B's action followed by B's continuation succeeds. When B supplies only this step, Q continues, searches for flights, writes a change and fails; when Q's failed lookup stands and B takes over, B fails too. % src: analysis/fork/out/ghf_20261001T211519Z.md (§4 Case 5)
The task value of an action is thus co-determined by the execution that follows it, and judging the action alone, however carefully, cannot reveal it.

The task benefit of a higher-precision upgrade thus depends on which step is upgraded and on who executes afterwards, and whole-model swap evaluations mix these effects. Recent work already forks live agent trajectories and continues them with a different model, against same-model control forks \citep{gonuguntla2026replay}; there, the new model writes the next action and everything after it, so the two cannot be told apart. Same-state crossed interventions measure them separately: we cross the source of the current action with the model that executes the rest of the episode, at a frozen state that replays bit-exactly, including the environment databases, the user simulator's view and the remaining step and error budget (\S\ref{sec:method}). The four branches measure on the same state the value of each upgrade mode: this step only, the rest of the episode, or both. A same-precision substitution, a second W4 checkpoint of the same model in place of B, tests whether turnover and continuation dependence require a higher bit width, and benchmarks B's substitution against a fixed-precision alternative. We study Qwen3-4B and Qwen3-8B under simulated weight and KV-cache quantization in \tautwo{} \citep{barres2025tau2}, BFCL multi-turn and ALFWorld. % nocheck: model sizes

\paragraph{Findings.}
\begin{itemize}[leftmargin=*,itemsep=1pt,topsep=2pt]
\item \textbf{Upgrade value is continuation-dependent} (\S\ref{sec:value}). Replacing a W4 agent's first tool-structure-divergent action with B's changes the outcome in 15.5--20.9\% of task$\times$block units, with rescues and damages of similar size and a net effect of $-1.9$ to $+2.9$\pp{} (Figure~\ref{fig:case}b). In 26.9\% of divergent states the swap has an effect under one continuation and none, or the opposite, under the other. Which upgrade mode produces net task gain differs by configuration (Figure~\ref{fig:modes}). % src: analysis/fork/out/dev_all_20261001T070326Z.md; analysis/fork/out/ghf_20261001T211519Z.md (§2)
\item \textbf{A higher bit width is not necessary for two-sided flips and continuation dependence} (\S\ref{sec:sameprec}). Swapping only the calibration checkpoint, at W4 and at W3, also produces them at comparable size. Even after accounting for the same tasks being flip-prone anyway, the two substitutions share affected units: at W4, 107 units flip under both, against 76 [69, 84] under a within-task block shuffle that keeps each task's flip propensity; yet 138 of the 245 affected units respond to only one of them. Equivalence of the two turnovers within $\pm$3\pp{} is not shown. % src: analysis/fork/out/sameprec_20261002T142834Z.md (Amendment A1); analysis/fork/out/sameprec_overlap_20261002T143218Z.md (Agreement, null within task); derived: 138=64+74; 245=107+64+74
\item \textbf{Detecting sensitivity is not selecting value} (\S\ref{sec:r4}). A frozen Q-only uncertainty trigger captures more outcome-changing decisions than random selection, but rescues and damages alike: 2--5 of the 34--38 net units that a hindsight oracle with the same budget shows are available. % src: analysis/fork/out/token_mech_20261002T003130Z.md (§3); analysis/fork/out/oracle_trigger_20261002T024423Z.md (§1a)
\end{itemize}

\paragraph{Contributions.} (1)~\emph{An executable same-state intervention protocol} that measures separately the value of upgrading the current action, the continuation, and both, with a same-precision reference substitution. The factorial design is standard; the contribution is making these counterfactuals executable and auditable in closed-loop agents (exact state restoration, budget accounting, replay acceptance, explicit denominators). (2)~\emph{The empirical structure of precision upgrades}: gains are two-sided and depend on the execution that follows, and sensitivity signals find outcome changes but do not yet reliably select net-beneficial substitutions. % nocheck: list labels (1)-(2)
