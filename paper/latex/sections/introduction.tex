\section{Introduction}
\label{sec:intro}

A low-precision LLM agent (Q) can retain its BF16 reference (B) as a fallback \citep{li2026dynamicmp}. Deciding when to use that fallback requires knowing the task benefit of a specific upgrade: B may \textbf{replace the current action, take over from the next step, or do both}. These choices intervene at different points in a closed-loop interaction. Average success rates compare complete agents, while KL and action disagreement describe local drift; neither directly measures what a particular fallback decision gains or loses.


Figure~\ref{fig:case} shows a decision from an airline task. Q looks up a reservation id that does not exist; B looks up the user's profile. We execute both actions and continue each with either model. Only BB succeeds. In this case, B's action helps only when B also continues. Evaluating the action alone misses that rescue. % src: analysis/fork/out/ghf_20261001T211519Z.md (§4 Case 5)

A model that takes over a forked trajectory writes both the next action and the continuation \citep{gonuguntla2026replay}. Their contributions are coupled in that evaluation. We separate them by crossing the action source with the continuing model at an audited, restored state (\S\ref{sec:replay}). Two reference interventions help interpret the outcome changes: substituting another W4 checkpoint (Q$'$), and reordering argument keys while preserving the tool operation. We study Qwen3-4B and Qwen3-8B \citep{yang2025qwen3} under simulated weight and KV-cache quantization in \tautwo{} \citep{yao2024tau,barres2025tau2}. Scope checks cover BFCL multi-turn \citep{patil2025bfcl}, ALFWorld \citep{shridhar2021alfworld}, and ordinary sampled states from Mistral-Small-3.2-24B \citep{mistral2025small32} (Table~\ref{tab:scope}). % nocheck: model sizes

\paragraph{Contributions.} We develop an auditable protocol for measuring three precision interventions on shared states. Building on step values under a continuing policy \citep{setlur2024rewarding}, the protocol combines action--continuation contrasts, paired rescue--damage accounting and two reference substitutions. Our empirical analysis identifies a gap in attributing task outcomes to precision: substitutions can change outcomes without increasing bit width or changing the executed tool operation. Establishing a need for higher precision therefore requires measuring the additional task benefit of the specified upgrade.

The experiments answer three questions:
\begin{enumerate}[leftmargin=*,itemsep=2pt,topsep=3pt]
\item \textbf{What does an upgrade change?} Replacing the current W4 action produces substantial rescues and damages, which largely cancel in the average. The telecom holdout has a negative estimate; its frozen protocol nevertheless classifies it as inconclusive (\S\ref{sec:value}).
\item \textbf{Do flips indicate a need for more bits?} A second W4 checkpoint and a semantically identical key-order change also alter outcomes. A direct common-state comparison does not establish either BF16's extra action value or equivalence (\S\ref{sec:sameprec}).
\item \textbf{Can sensitivity guide selection?} One frozen Q-only rule finds more outcome-changing decisions than random selection, but no tested rate reliably improves net gain after correction (\S\ref{sec:r4}).
\end{enumerate}
