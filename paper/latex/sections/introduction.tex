\section{Introduction}
\label{sec:intro}

A low-precision LLM agent (Q) can retain its BF16 reference (B) as a fallback \citep{li2026dynamicmp}. Deciding when to use that fallback requires knowing the task benefit of a specific upgrade: B may \textbf{replace the current action, take over from the next step, or do both}. These choices intervene at different points in a closed-loop interaction. Average success rates compare complete agents, while KL and action disagreement describe local drift; neither directly measures what a particular fallback decision gains or loses.


Figure~\ref{fig:case} shows one decision from our data: Q looks up a reservation id that does not exist, B looks up the user's profile, and of the four combinations \{B's or Q's action\} $\times$ \{B or Q continuing\} at the frozen state only BB succeeds. B's action is worth a success only if B also continues, which no evaluation of the action alone can show. The case illustrates the measurement distinction; it is not evidence for a mechanism. % src: analysis/fork/out/ghf_20261001T211519Z.md (§4 Case 5)

When a forked trajectory is continued with another model \citep{gonuguntla2026replay}, that model writes both the next action and everything after it, so the two effects cannot be separated. We cross the source of the current action with the model that executes the rest of the episode, at a frozen state whose exact replay we audit (\S\ref{sec:replay}), and read the results against two reference interventions: a second W4 checkpoint of the same model (Q$'$) in place of B, and an argument key-order change that leaves the tool operation identical. We study Qwen3-4B and Qwen3-8B \citep{yang2025qwen3} under simulated weight and KV-cache quantization in \tautwo{} \citep{yao2024tau,barres2025tau2}; BFCL multi-turn \citep{patil2025bfcl} and ALFWorld \citep{shridhar2021alfworld} (other environments) and Mistral-Small-3.2-24B \citep{mistral2025small32} (a second model family, forked at sampled \tautwo{} states) are scope checks (Table~\ref{tab:scope}). % nocheck: model sizes

\paragraph{Contributions.} We develop an auditable protocol for measuring three precision interventions on shared states. Building on step values under a continuing policy \citep{setlur2024rewarding}, the protocol combines action--continuation contrasts, paired rescue--damage accounting and two reference substitutions. Our empirical analysis separates a decision's sensitivity to substitution from the additional task value of higher precision.

The experiments answer three questions:
\begin{enumerate}[leftmargin=*,itemsep=2pt,topsep=3pt]
\item \textbf{What does an upgrade change?} Replacing the current W4 action produces substantial rescues and damages, which largely cancel in the average. The telecom holdout has a negative estimate; its frozen protocol nevertheless classifies it as inconclusive (\S\ref{sec:value}).
\item \textbf{Do flips indicate a need for more bits?} A second W4 checkpoint and a semantically identical key-order change also alter outcomes. A direct common-state comparison does not establish either BF16's extra action value or equivalence (\S\ref{sec:sameprec}).
\item \textbf{Can sensitivity guide selection?} One frozen Q-only rule finds more outcome-changing decisions than random selection, but no tested rate reliably improves net gain after correction (\S\ref{sec:r4}).
\end{enumerate}
