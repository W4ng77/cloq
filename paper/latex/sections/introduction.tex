\section{Introduction}
\label{sec:intro}

A quantized LLM agent (Q) is cheaper to serve than its BF16 reference (B), and a deployment can keep B as a fallback \citep{li2026dynamicmp}. Evaluations usually report how far Q drifts from B. A fallback needs the task value of one specified upgrade: at a decision where B would act differently, B can \textbf{replace only this step, take over from the next step, or both}. A more sensitive model, a more different action or a more changeable outcome does not by itself show that an upgrade helps, and average success does not answer the question: on our checkpoints, Q's success minus B's ranges from $-0.2$ to $+4.2$\pp{} across four W4 configurations (a configuration is one model under one quantization setting), and equivalence within $\pm$3\pp{} is not established in any of them (Appendix~\ref{app:e2e}). % src: analysis/insights/iter_4/out/success_ni_ALIGNED_20260930T213009Z.md

Figure~\ref{fig:case} shows one decision from our data. In an airline task, Q looks up a reservation id that does not exist; B looks up the user's profile. We froze the state and ran all four combinations of \{B's or Q's action\} $\times$ \{B or Q continuing\}. Only B's action followed by B's continuation succeeds. When B supplies only this step and Q continues, the task fails; when Q's failed lookup stands and B takes over, it fails too. % src: analysis/fork/out/ghf_20261001T211519Z.md (§4 Case 5)
Here B's action is worth a success only if B also continues, and no evaluation of the action alone can show that. The case illustrates the measurement distinction; it is not evidence for a mechanism.

When a forked trajectory is continued with another model \citep{gonuguntla2026replay}, that model writes both the next action and everything after it, so the two effects cannot be separated. We cross the source of the current action with the model that executes the rest of the episode, at a frozen state whose exact replay we audit (\S\ref{sec:replay}). We read the results against two reference interventions: a second W4 checkpoint of the same model (Q$'$) in place of B, and an argument key-order change that leaves the tool operation identical. We study Qwen3-4B and Qwen3-8B \citep{yang2025qwen3} under simulated weight and KV-cache quantization in \tautwo{} \citep{yao2024tau,barres2025tau2}; BFCL multi-turn \citep{patil2025bfcl} and ALFWorld \citep{shridhar2021alfworld} (other environments) and Mistral-Small-3.2-24B \citep{mistral2025small32} (a second model family, forked at sampled \tautwo{} states) are scope checks (Table~\ref{tab:scope}). % nocheck: model sizes

\paragraph{Contribution.} Our contribution is an evaluation protocol for the task value of a precision upgrade, and two reference experiments that show why sensitivity-based inferences about that value fail. It makes three targets explicit:
\begin{itemize}[leftmargin=*,itemsep=1pt,topsep=2pt]
\item \emph{Measurement target.} Replacing the current action, taking over the continuation and replacing both are different interventions, each measured on the same state by its rescues and damages; a gain measured for one is not reused for another.
\item \emph{Interpretation reference.} A same-bit-width checkpoint produces two-sided consequences, and a representation change that keeps the tool operation identical also changes outcomes (rescues and damages both observed; exploratory). Flips are read against these references, not subtracted from B's.
\item \emph{Selection target.} Selecting decisions that change outcomes and selecting upgrades with positive net value are separate goals; we test a frozen rule against random and oracle selection with the same budget.
\end{itemize}
Valuing a step under the continuing policy and factorial forking are standard \citep{setlur2024rewarding}; what we add is the three contrasts applied to precision upgrades at shared states, the two references, and the replay audit.

\paragraph{Findings.}
\begin{itemize}[leftmargin=*,itemsep=1pt,topsep=2pt]
\item \textbf{An upgrade has two-sided consequences} (\S\ref{sec:value}). Replacing a W4 agent's first tool-structure-divergent action with B's changes 15.5--20.9\% of task outcomes, with rescues and damages of similar size; pooled over the four W4 configurations the net is $+0.7$\pp{} (95\% over new tasks [$-2.1$, $+3.4$]). In post hoc analyses, testing the action alone ($G$) and testing the joint replacement alone ($F$) each miss rescues that the other counts. A pre-registered telecom holdout again shows rescues and damages. Its net estimate is $-4.6$\pp{}; the frozen decision rule, which had no negative category, classifies it as inconclusive, and both pre-registered secondary checks passed. % src: analysis/fork/out/dev_all_20261001T070326Z.md; analysis/fork/out/dev_all_20261001T070326Z.json (pooled.W4:all:pooled_equal_weight.G.crossed_ci95); analysis/fork/out/holdout_confirm_20261002T012353Z.md (TL;DR; Readings; S1; S2); analysis/fork/out/outcome_classes_20261004T143614Z.md
\item \textbf{Flips alone do not diagnose a need for more bits} (\S\ref{sec:sameprec}). Under a protocol frozen before any outcome, a second checkpoint at the same bit width also produces two-sided flips and continuation dependence (turnover 17.7\% against 16.8\% for B on the same blocks; equivalence to B not shown). At common states B's extra action value over it is not established, nor is equivalence. Reversing tool-argument key order, which leaves the operation identical, changes 6.7\% of outcomes on 300 eligible states, not distinguished from 9.0\% for B's action (exploratory). % src: analysis/fork/out/sameprec_20261004T070601Z.md (Amendment A1; TL;DR; Full pool, pool rows); analysis/fork/out/commonstate_q8ext_20261003T231159Z.md; analysis/fork/out/keyorder_20261005T204349Z.md
\item \textbf{Selecting sensitive decisions is not selecting valuable upgrades, for one frozen rule} (\S\ref{sec:r4}). A frozen Q-only margin trigger selects more outcome-changing decisions than random at two of three escalation rates, rescues and damages alike. Its net gains ($+4$, $+2$ and $+5$ of 1020 states) are not reliably above random expectations ($+0.21$, $+0.98$, $+2.38$; no rate survives Holm correction); a hindsight oracle with the same budget nets $+34$, $+38$ and $+38$. The rule was tested only on later blocks of the development tasks. % src: analysis/fork/out/token_mech_20261002T003130Z.md (§3); analysis/fork/out/oracle_trigger_20261002T024423Z.md (§1a)
\end{itemize}
