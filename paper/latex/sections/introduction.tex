\section{Introduction}
\label{sec:intro}

Precision fallback offers a way to intervene when a low-precision agent struggles: call the BF16 model at a selected point in the interaction \citep{li2026dynamicmp}. Yet the intervention still has to improve the task. The BF16 model may \textbf{replace the current action, take over from the next step, or do both}. Each choice changes a different part of the running trajectory. We ask how much task success each choice gains or loses.

This local question is not answered by comparing complete agents. An end-to-end score measures a model running from the start; a fallback inserts it into a history built by another model. Nor does disagreement reveal the value of the insertion. KL and action differences describe how the models diverge. A changed action can rescue a failure, damage a success, or leave the final outcome intact. The useful quantity is the number of rescues minus the number of damages.


Figure~\ref{fig:case}a shows a decision from an airline task. Q looks up a reservation id that does not exist; B looks up the user's profile. We execute both actions and continue each with either model. Only BB succeeds. In this case, B's action helps only when B also continues. Evaluating the action alone misses that rescue. % src: analysis/fork/out/ghf_20261001T211519Z.md (§4 Case 5)

A model that takes over a forked trajectory writes both the next action and the continuation \citep{gonuguntla2026replay}. We measure their contributions separately by running all four action--continuation combinations from the same restored state. We then test an attribution that a flip count leaves open: did the outcome change require higher precision? Another W4 checkpoint (Q$'$) changes the action without increasing bit width. Reordering tool-argument keys changes the representation without changing the operation. These references give outcome sensitivity a concrete interpretation. We study Qwen3-4B and Qwen3-8B \citep{yang2025qwen3} under simulated weight and KV-cache quantization in \tautwo{} \citep{yao2024tau,barres2025tau2}. Scope checks cover BFCL multi-turn \citep{patil2025bfcl}, ALFWorld \citep{shridhar2021alfworld}, and ordinary sampled states from Mistral-Small-3.2-24B \citep{mistral2025small32} (Appendix~\ref{app:scope}). % nocheck: model sizes

\paragraph{Contributions.} We contribute a measurement protocol and an empirical test of precision attribution. The protocol separates action replacement from later takeover, measures their rescues and damages on shared states, and checks the baseline through exact replay. It builds on established step values under a continuing policy \citep{setlur2024rewarding}. The empirical study combines same-precision and unchanged-operation references with a direct comparison of BF16 and W4 actions. Together, they show why a decision's sensitivity to substitution is insufficient evidence that it needs more bits. We also test whether an uncertainty-based selector converts that sensitivity into task benefit.

Three findings build this argument:
\begin{enumerate}[leftmargin=*,itemsep=2pt,topsep=3pt]
\item \textbf{A fallback can save tasks and spoil others.} W4 action replacement produces substantial changes in both directions, with little pooled net gain. The action-only estimate is negative on new telecom tasks (\S\ref{sec:value}).
\item \textbf{A flip does not identify a precision deficit.} Changing the W4 checkpoint or only the tool-argument order can alter the outcome. The direct shared-state comparison leaves BF16's additional action value unresolved (\S\ref{sec:sameprec}).
\item \textbf{Finding sensitive decisions is only part of selection.} Our frozen uncertainty rule finds more outcome changes than random selection, without establishing a net-benefit advantage (\S\ref{sec:r4}).
\end{enumerate}
