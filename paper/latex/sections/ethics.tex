\section*{Ethics Statement}

This work involves no crowdworkers, no human annotation and no personal data. Where a user is present (\tautwo{}), it is simulated by an LLM; tasks are public benchmark tasks, and all agents are openly released Qwen3, Mistral-Small-3.2 and (gate check only) Llama-3.1 checkpoints, or simulated-quantized versions of them. Outcomes use the automatic task-success endpoints defined in \S\ref{sec:setting}, including the database-only retail and airline checks, and action categories are assigned by fixed rules; reported values map to committed analysis outputs (Appendix~\ref{app:figsrc}). % nocheck: model names
The main risk we see is over-reading. A small forked-state gain on one simulator and a fixed task pool does not certify a quantized agent for deployment, and our end-to-end comparisons do not establish equivalence. Deployment decisions in consequential settings should not rest on these measurements alone.
