\paragraph{Rescues and damages are both large; the pooled net is not resolved.} On the \tautwo{} development panel (85 tasks $\times$ 20 complete blocks), replacing a W4 agent's action at the first divergent state with B's, while Q continues, changes 15.5--20.9\% of task outcomes, with rescues and damages of similar size (Figure~\ref{fig:rd}a). Two fixed-pool intervals of the net exclude zero (negative for q4 GPTQ-W4, positive for q8 GPTQ-W4); no new-task interval does. Pooled over the four W4 configurations, the net is $+0.7$\pp{} (fixed pool [$-0.3$, $+1.6$]; new tasks [$-2.1$, $+3.4$]). The net is a local replacement effect, not an end-to-end comparison (Appendix~\ref{app:e2e}). % src: analysis/fork/out/dev_all_20261001T070326Z.md (cells; W4:all pooled row: G block bootstrap, M); analysis/fork/out/dev_all_20261001T070326Z.json (pooled.W4:all:pooled_equal_weight.G.crossed_ci95)

\paragraph{On held-out telecom tasks the net estimate is negative, and the frozen reading is inconclusive.} On 34 unseen telecom tasks, under a protocol frozen before any holdout unit ran (12 fresh blocks, three W4 configurations), the replacement again rescued and damaged units (Figure~\ref{fig:rd}b). The primary net, $-4.57$\pp{} (crossed 90\% [$-7.17$, $-1.96$]), lies below zero. The frozen readings had only positive-gain and small-effect categories, a design omission, so the protocol classifies the result as \emph{inconclusive} (Figure~\ref{fig:rd}b; Appendix~\ref{app:prereg}). Both pre-registered secondary checks passed: S1 (rescues and damages both positive) and S2 (cross-half repeatability of task fragility, $\rho=0.588$, one-sided permutation $p=0.0001$). % src: analysis/fork/out/holdout_confirm_20261002T012353Z.md (TL;DR; Readings; S1; S2); docs/insights/PREREG_FORK_CONFIRM.md §0, §8

\paragraph{Which mode is evaluated decides which rescues are counted (exploratory, post hoc).} On divergent states no average gain is detected for upgrading this step ($G$), the rest ($H$) or both ($F$; every W4-pool interval covers zero; Figure~\ref{fig:rd}c, Appendix~\ref{app:r2main}). % src: analysis/fork/out/ghf_20261001T211519Z.md (§1 pools, W4:all); analysis/fork/out/ghf_20261001T211519Z.json
Single-mode evaluations disagree at some states: in a \emph{joint rescue} only BB succeeds (Figure~\ref{fig:case}), which testing only $G$ misses; in a \emph{rescue undone}, B's action rescues under Q's continuation but fails under B's, which testing only $F$ misses (observed shares: Figure~\ref{fig:rd}d, obs / ref column; Appendix~\ref{app:offdiag}). A label-permutation reference that keeps how many branches succeed produces both patterns at similar rates, so their frequency gives no evidence of enrichment that generalises to new tasks. Whatever their cause, a gain measured for $G$ cannot be reused as the gain of $F$, or the reverse. % src: analysis/fork/out/pattern_ref_20261005T134721Z.md (§1, pool W4:all); analysis/fork/out/outcome_classes_20261004T143614Z.md

\paragraph{Pointers.} Outcome changes recur on the same tasks across nonce blocks (post hoc; this does not predict which new tasks are fragile; Appendix~\ref{app:concentration}). Exploratory follow-ups (Appendices~\ref{app:transfer} and~\ref{app:takeover}) carry no main-text claim.
