\paragraph{Large outcome changes, small net estimate.} On the \tautwo{} development panel (85 tasks $\times$ 20 complete blocks), replacing a W4 agent's action at the first divergent state with B's, while Q continues, changes 15.5--20.9\% of task outcomes, with rescues and damages of similar size (Figure~\ref{fig:rd}a). Two fixed-pool intervals of the net exclude zero (negative for q4 GPTQ-W4, positive for q8 GPTQ-W4); no new-task interval does. Pooled over the four W4 configurations, the net is $+0.7$\pp{} (fixed pool [$-0.3$, $+1.6$]; new tasks [$-2.1$, $+3.4$]). The net is a local replacement effect, not an end-to-end comparison (Appendix~\ref{app:e2e}). % src: analysis/fork/out/dev_all_20261001T070326Z.md (cells; W4:all pooled row: G block bootstrap, M); analysis/fork/out/dev_all_20261001T070326Z.json (pooled.W4:all:pooled_equal_weight.G.crossed_ci95)

\paragraph{A negative holdout estimate.} On 34 unseen telecom tasks, under a protocol frozen before any holdout unit ran (12 fresh blocks, three W4 configurations), the replacement again rescued and damaged units (Figure~\ref{fig:rd}b). The primary net, $-4.57$\pp{} (crossed 90\% [$-7.17$, $-1.96$]), lies below zero. The frozen readings had only positive-gain and small-effect categories, a design omission, so the protocol classifies the result as \emph{inconclusive} (Figure~\ref{fig:rd}b; Appendix~\ref{app:prereg}). Both pre-registered secondary checks passed: S1 (rescues and damages both positive) and S2 (cross-half repeatability of task fragility, $\rho=0.588$, one-sided permutation $p=0.0001$). % src: analysis/fork/out/holdout_confirm_20261002T012353Z.md (TL;DR; Readings; S1; S2); docs/insights/PREREG_FORK_CONFIRM.md §0, §8
A post hoc QQ no-op replay of all 1202 divergent states, under a protocol frozen before any replay ran, reproduced every original episode, so the baseline shared by all holdout contrasts is not a replay artifact. The holdout changes domain as well as tasks (Appendix~\ref{app:holdoutdev}). % src: analysis/fork/out/holdout_qqfull_audit_20261006T061033Z.md (TL;DR); docs/insights/HOLDOUT_QQFULL_PROTOCOL.md (§1-§5, Amendment 1); docs/insights/PREREG_FORK_CONFIRM.md §1

\paragraph{The intervention defines which rescues count.} A joint rescue succeeds only when both the current action and the continuation change (Figure~\ref{fig:case}); action-only evaluation misses it. Conversely, a rescue under Q's continuation can disappear when B also takes over, so whole-takeover evaluation can miss a useful action-only replacement. These observed patterns illustrate why $G$, $H$ and $F$ are separate targets. Their full counts and permutation references are exploratory and appear in Appendix~\ref{app:offdiag}; a gain measured for one mode cannot be reused as the gain of another.
