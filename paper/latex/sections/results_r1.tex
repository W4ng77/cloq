\paragraph{Many rescues, many damages, small net.} On the \tautwo{} development panel (85 tasks $\times$ 20 complete blocks), replacing a W4 agent's first tool-structure-divergent action with B's, while Q continues, changes the task outcome in $M=15.5$--$20.9$\% of units (Figure~\ref{fig:case}b). Rescues and damages are of similar size, $r=6.8$--$11.4$ and $d=7.5$--$10.1$\pp{}, so the net gain $\Gall$ lies between $-1.9$ and $+2.9$\pp{}. Two fixed-pool intervals exclude zero (negative for q4 GPTQ-W4, positive for q8 GPTQ-W4); no new-task interval does. KV8 cells turn over fewer outcomes ($M=6.5$--$8.1$\%, a descriptive comparison). $\Gall$ is a local replacement effect, not an end-to-end comparison (Appendix~\ref{app:e2e}). % src: analysis/fork/out/dev_all_20261001T070326Z.md
Pooled over the four W4 cells, $\Gall=+0.7$\pp{} (fixed pool [$-0.4$, $+1.6$]; new tasks [$-2.1$, $+3.5$]) with $M=18.6$\%. % src: analysis/fork/out/task_fragility_20261005T134836Z.md (Full pool, pool G block and crossed); analysis/fork/out/dev_all_20261001T070326Z.md (M)
On 34 unseen telecom tasks, under a protocol frozen before any holdout unit ran (12 fresh blocks, three W4 cells), the replacement again rescued and damaged ($r=5.2$, $d=9.8$\pp{}). The primary $\Gall=-4.57$\pp{} (crossed 90\% [$-7.17$, $-1.96$]) is \emph{inconclusive} by the pre-registered readings, which had no negative category; outside them, the interval lies below zero (Appendix~\ref{app:prereg}). \paragraph{The consequences recur on the same tasks.} We split the 20 nonce blocks into two halves by an outcome-independent hash of the block name (written before this post hoc analysis loads outcomes), ranked tasks by turnover on one half and measured the other half (Table~\ref{tab:fragility}). The 17 most fragile tasks (top 20\%) carry 41.0\% (crossed [26.6, 55.9]) and 42.3\% ([27.0, 57.5]) of the held-out turnover in the two directions, against 20\% if fragility did not persist. Their turnover is 38.7\%, while the other 68 tasks still turn over 13.7\%. Both groups have rescues and damages; neither group's net gain is resolved under the crossed interval (Appendix~\ref{app:concentration}). This replicates fragility on other nonces of the same tasks; it does not predict which new tasks are fragile. % src: analysis/fork/out/task_fragility_20261005T134836Z.md (Split-half fragility, both directions); analysis/fork/out/task_fragility_split_20261005T134815Z.json; derived: 68=85-17

\paragraph{Which mode is evaluated decides which rescues are counted.} On divergent states, the average effect of the action swap has the same point estimate under Q's and B's continuation (W4 pool: $\DQ=G=+0.5$, fixed pool [$-0.7$, $+1.7$], new tasks [$-2.9$, $+3.8$]; $\DB=+0.5$, [$-1.0$, $+2.1$], [$-3.5$, $+4.5$]\pp{}), and no average gain is detected for upgrading this step, the rest, or both ($H=+0.2$, $F=+0.7$\pp{}, all intervals covering zero). % src: analysis/fork/out/ghf_20261001T211519Z.md (§1 pools, W4:all; F - H = Δ_B); analysis/fork/out/ghf_20261001T211519Z.json
The averages hide states on which the single-mode evaluations disagree (exploratory, post hoc; \% of W4 divergent states; fixed-pool, then new-task 95\% intervals). In a \emph{joint rescue}, 4.0\% ([3.5, 4.5]; [2.7, 5.3]), only $\YY{BB}$ succeeds (Figure~\ref{fig:case}a): testing only the current action misses states where B's action needs B's continuation too. In a \emph{rescue undone}, 4.8\% ([4.1, 5.4]; [3.2, 6.5]), B's action rescues under Q's continuation ($\YY{BQ}=1$, $\YY{QQ}=0$) but B's takeover undoes it ($\YY{BB}=0$): testing only a whole takeover, which swaps the action and everything after it, misses an action-level rescue that holds under Q's continuation. % src: analysis/fork/out/outcome_classes_20261004T143614Z.md
A conditional label-permutation reference (which keeps how many of the four branches succeed) already produces both patterns at similar size (joint rescue 4.0\% vs 3.5\%; rescue undone 4.8\% vs 5.8\%); the observed frequencies give no generalisable evidence of extra enrichment (Appendix~\ref{app:offdiag}). The reference does not model execution, so it does not say how these outcomes arise. The patterns matter as an evaluation consequence: action replacement and whole takeover cannot share one gain label. Paired comparisons of the three modes, by cell, are in Appendix~\ref{app:r2main}. % src: analysis/fork/out/pattern_ref_20261005T134721Z.md (§1, pool W4:all)
