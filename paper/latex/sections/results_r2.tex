 A flip shows that an outcome is sensitive to substitution. To ask whether it indicates a need for higher precision, we compare BF16 with two reference interventions (Figure~\ref{fig:refs}). Their populations and comparison targets differ, so each reference answers a distinct question. % nocheck: step labels

\paragraph{A same-precision checkpoint also changes outcomes.} Q$'$ replaces the current action without increasing bit width. On the matched W4 task--block panel it produces 17.7\% turnover, compared with 16.8\% for BF16, with rescues and damages in both directions (Figure~\ref{fig:refs}a). Changing the W3 checkpoint produces the same qualitative pattern. These are observed turnover estimates; equivalence within $\pm$3\pp{} is not established. % src: analysis/fork/out/sameprec_20261004T070601Z.md; docs/insights/SAMEPREC_PROTOCOL.md

\paragraph{An identical tool operation can lead to a different outcome.} At 300 eligible q8 states, we reverse only the order of Q's tool-argument keys. Every perturbed call parses to the same arguments and produces the same environment effects; the agent subsequently reads a different token sequence. Outcomes change on 6.7\% of these states, versus 9.0\% when replacing the action with BF16's (Figure~\ref{fig:refs}b). The paired turnover difference is $-2.3$\pp{} [$-8.4$, $+2.9$], leaving the difference unresolved. This exploratory reference covers one representation change on 41 tasks, rather than a general perturbation distribution (Appendix~\ref{app:keyorder}). % src: analysis/fork/out/keyorder_20261005T204349Z.md; docs/insights/KEYORDER_PERTURB_PROTOCOL.md

\paragraph{Shared states isolate the additional value of BF16.} The preceding design selects each substitute's own first divergence. It compares two selection-and-replacement protocols, rather than two actions at the same decision. We therefore compare B and Q$'$ directly at 510 shared ordinary q8 states. BF16's extra action value is $+1.0$\pp{} under Q's continuation (two-look 97\% block-$t$ interval [$-4.2$, $+6.2$]) and $+0.8$\pp{} under B's ([$-2.2$, $+3.8$]; Figure~\ref{fig:refs}c). Both comparisons remain unresolved and neither establishes equivalence. The six-block extension and two-look rule were fixed after the unresolved first look; the timeline, bootstrap intervals and sensitivity excluding earlier studied states are in Appendix~\ref{app:commonstate}. % src: analysis/fork/out/commonstate_q8ext_20261003T231159Z.md; docs/insights/COMMONSTATE_SOURCES_PROTOCOL.md

Together, the references establish a limit on interpreting flips: a changed outcome does not identify a decision that needs higher precision. The additional task value of BF16 requires a direct paired comparison of actions under the continuation that will run.
