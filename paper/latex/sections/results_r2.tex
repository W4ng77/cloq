An outcome can flip without either more bits or a different tool operation. A flip therefore shows sensitivity to substitution. To ask whether it indicates a need for higher precision, we compare BF16 with two reference interventions (Figure~\ref{fig:refs}). Each reference answers a different question on its own state population. % nocheck: step labels

\paragraph{A same-precision checkpoint also changes outcomes.} Q$'$ replaces the current action without increasing bit width. On the matched W4 task--block panel it produces 17.7\% turnover, compared with 16.8\% for BF16, with rescues and damages in both directions (Figure~\ref{fig:refs}a). The W3 stress comparison also shows bidirectional changes (Appendix~\ref{app:qprime}). These are observed turnover estimates; equivalence within $\pm$3\pp{} is not established. % src: analysis/fork/out/sameprec_20261004T070601Z.md; docs/insights/SAMEPREC_PROTOCOL.md

\paragraph{An identical tool operation can lead to a different outcome.} At 300 eligible Qwen3-8B states, we reverse Q's tool-argument key order. The call still parses to the same arguments and produces the same environment effects. Only the token sequence read by the agent changes. Outcomes change on 6.7\% of these states, versus 9.0\% when replacing the action with BF16's (Figure~\ref{fig:refs}b). The paired turnover difference (BF16 minus key reversal) is $+2.3$\pp{} [$-2.9$, $+8.4$], leaving the difference unresolved. This exploratory reference covers one representation change on 41 tasks, rather than a general perturbation distribution (Appendix~\ref{app:keyorder}). % src: analysis/fork/out/keyorder_20261005T204349Z.md; docs/insights/KEYORDER_PERTURB_PROTOCOL.md

\paragraph{Shared states isolate the additional value of BF16.} The same-precision panel selects each substitute's own first divergence. It compares two selection-and-replacement protocols, rather than two actions at the same decision. We therefore compare B and Q$'$ directly at 510 shared ordinary states from Qwen3-8B BF16 histories. The extra action value is $+1.0$\pp{} with Q continuing and $+0.8$\pp{} with B continuing. Both remain unresolved, and equivalence is not established. Appendix~\ref{app:commonstate} gives the adjusted intervals and the reading rule adopted after an unresolved first look. The experiment neither establishes BF16 as better nor rules out a useful advantage. % src: analysis/fork/out/commonstate_q8ext_20261003T231159Z.md; docs/insights/COMMONSTATE_SOURCES_PROTOCOL.md

These references expose two routes to changed outcomes: changing the policy without increasing bit width, and changing the representation without changing the tool operation. Their role is to test attribution, rather than estimate a universal noise floor to subtract from turnover.

Together, the references establish a limit on interpreting flips: a changed outcome does not identify a decision that needs higher precision. The additional task value of BF16 requires a direct paired comparison of actions under the continuation that will run.
