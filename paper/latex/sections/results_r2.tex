Both reference interventions change outcomes without increasing bit width (Figure~\ref{fig:refs}). One changes the checkpoint; the other leaves the tool operation unchanged. They test whether observing a flip is enough to attribute the consequence to a precision deficit. % nocheck: step labels

\paragraph{Changing the checkpoint is enough to produce flips.} On the matched W4 task--block panel, substituting Q$'$ produces 17.7\% turnover, compared with 16.8\% for BF16 (Figure~\ref{fig:refs}a). Both substitutions rescue and damage tasks. Thus large outcome changes also occur when bit width stays fixed. The estimates do not establish equivalence within $\pm$3\pp{}. The W3 stress comparison also changes outcomes in both directions (Appendix~\ref{app:qprime}). % src: analysis/fork/out/sameprec_20261004T070601Z.md; docs/insights/SAMEPREC_PROTOCOL.md

\paragraph{Changing the representation is also enough.} At 300 eligible Qwen3-8B states, we reverse the order of keys in Q's tool arguments. Parsing gives exactly the same call, and execution gives exactly the same environment effects. The agent reads a different token sequence afterward. That change alone alters 6.7\% of outcomes; replacing the action with BF16's alters 9.0\% on the same states (Figure~\ref{fig:refs}b). Their paired difference, BF16 minus key reversal, is $+2.3$\pp{} [$-2.9$, $+8.4$]. The difference remains unresolved. This exploratory experiment covers one representation change on 41 tasks (Appendix~\ref{app:keyorder}). % src: analysis/fork/out/keyorder_20261005T204349Z.md; docs/insights/KEYORDER_PERTURB_PROTOCOL.md

\paragraph{Extra precision needs a direct value comparison.} The first experiment chooses each substitute's own first divergence. It therefore does not compare B and Q$'$ at identical decisions. We make that comparison at 510 shared ordinary states from Qwen3-8B BF16 histories, keeping the continuation fixed. BF16's extra action value is $+1.0$\pp{} with Q continuing and $+0.8$\pp{} with B continuing. The adjusted intervals leave both effects unresolved and do not establish equivalence. A useful BF16 advantage remains possible. Appendix~\ref{app:commonstate} gives the intervals and the expansion and reading rules adopted after the first look. % src: analysis/fork/out/commonstate_q8ext_20261003T231159Z.md; docs/insights/COMMONSTATE_SOURCES_PROTOCOL.md

The references support a specific conclusion: outcome sensitivity alone cannot identify a need for higher precision. They expose changes that require neither additional bits nor a different tool operation. They are not a noise floor to subtract from BF16's turnover. To establish the value of more bits, compare the signed task benefit of the alternatives on the same states and under the same continuation.
