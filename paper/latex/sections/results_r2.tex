\paragraph{The question and its three designs.} If the consequences in \S\ref{sec:value} required a higher bit width, a substitution at the same bit width should produce markedly fewer of them. Table~\ref{tab:refs} lists three reference designs; the argument takes four steps, and Step 2 is a limit of the first design. Each is a reference intervention, compared with B's action only within its own population (status in Table~\ref{tab:refs}), and never subtracted from B's turnover to obtain a precision-specific effect. % nocheck: step labels

\paragraph{Step 1: a higher bit width is not necessary for two-sided flips or continuation dependence.} Both also appear when only the calibration checkpoint is swapped. At W4 (six blocks, the longest complete prefix under the frozen rule), Q$'$'s action rescues 9.3\pp{} of units (fixed pool [7.0, 11.7]; new tasks [5.9, 13.2]) and damages 8.4\pp{} ([6.4, 10.5]; [5.5, 12.0]). Its turnover is 17.7\%, against 16.8\% for B on the same six blocks and two GPTQ-W4 configurations. The swap's effect depends on the continuation in 26.2\% of its divergent states, against 25.0\% for B. Each same-precision rate has a fixed-pool 95\% lower bound above zero. % src: docs/insights/SAMEPREC_PROTOCOL.md (A1.3, 95% lower bound); analysis/fork/out/sameprec_20261004T070601Z.md (TL;DR; Full pool; On divergent states; analysis set K = 6); analysis/fork/out/sameprec_20261004T070601Z.json (pooled.same.rescue/damage.crossed_ci95)
A W3 stress pair also shows two-sided flips and continuation dependence when only the W3 checkpoint is swapped (turnover 17.3\% for Q$'$ against 18.8\% for B; Appendix~\ref{app:qprime}). Flip rate and continuation dependence alone therefore cannot diagnose a need for a higher bit width. We do not claim the turnovers are equal: neither pair is equivalent within $\pm$3\pp{}. % src: analysis/fork/out/sameprec_w3_20261004T070607Z.md (TL;DR; Full pool, pool rows); analysis/fork/out/sameprec_20261004T070601Z.md (Amendment A1 table)

\paragraph{Step 2: because each design picks its own divergent states, this comparison cannot measure what B adds.} Each design forks at its own first divergence, so flips found by only one design cannot be read as caused by precision, nor flips found by both as not caused by it. The action-side net difference, $-1.6$\pp{} (B minus Q$'$; fixed pool [$-6.2$, $+3.0$], new tasks [$-6.5$, $+3.6$]), is not resolved and compares two selection-and-replacement protocols, not two actions at one state (Appendix~\ref{app:qprime}). % src: analysis/fork/out/sameprec_split_20261002T145148Z.md (TL;DR; §3); analysis/fork/out/sameprec_20261004T070601Z.json (pooled.paired.dG.crossed_ci95); analysis/fork/out/sameprec_20261004T070601Z.md (Paired differences, pool row)

\paragraph{Step 3: at common states, B's extra action value over Q$'$ is not resolved, and equivalence is not shown.} A pre-registered comparison holds the states fixed: on 510 ordinary q8 GPTQ-W4 states (85 tasks $\times$ 6 blocks), the current action comes from B, Q or Q$'$, and B or Q continues (Table~\ref{tab:refs}). What B's action adds beyond Q$'$'s at the same state and under the same continuation is $+1.0$\pp{} under Q's continuation and $+0.8$\pp{} under B's. The first look, at three blocks, was unresolved; dated amendments then fixed an extension to six blocks and designated a two-look reading confirmatory, before any extension outcome existed. Neither value is resolved under that reading (97\% $t$ [$-4.2$, $+6.2$] and [$-2.2$, $+3.8$]) or unadjusted (95\% $t$ [$-3.5$, $+5.4$] and [$-1.8$, $+3.3$]). Under B's continuation the unadjusted 90\% interval lies within $\pm$3\pp{} ([$-1.2$, $+2.8$]), but the two-look 94\% interval does not ([$-1.6$, $+3.2$]), so we claim no equivalence; Appendix~\ref{app:commonstate} explains why we print both readings. q4 (two blocks) is also not resolved. % src: docs/insights/COMMONSTATE_SOURCES_PROTOCOL.md (§2, §5, §6; A1.1, A1.3; D2.2); analysis/fork/out/commonstate_q8ext_20261003T231159Z.md (TL;DR; Key estimand table, t95 and t90; Two-look reading table, t97 and t94); analysis/fork/out/commonstate_q4_20261004T001159Z.md (TL;DR, q4 K)

\paragraph{Step 4: an outcome can change while the tool operation stays identical.} Steps 1--3 change which model writes the action; Step 4 changes only the token representation of Q's own action. At 300 first divergent states of q8 GPTQ-W4 where Q's action is one tool call with at least two argument keys (41 tasks; airline 187, retail 113), we reverse the order of the top-level keys. The reordered call was checked to parse and execute identically, so only the next tokens the agent reads change. This changes the outcome in 6.7\% of these states ([0.8, 14.4]), against 9.0\% [2.9, 18.2] for B's action on the same states. The difference, $-2.3$\pp{} [$-8.4$, $+2.9$], is not resolved, and we claim no equivalence. Some outcome changes therefore arise without any change to the tool operation. The result covers only these states and this one change, not free-text or other representation changes, and it is not a perturbation curve (Appendix~\ref{app:keyorder}). % src: analysis/fork/out/keyorder_20261005T204349Z.md; analysis/fork/keyorder/eligibility_v1.md; docs/insights/KEYORDER_PERTURB_PROTOCOL.md (intervals: widest of block and crossed bootstrap on the pooled ratio)

\paragraph{What the four steps establish.} In these designs, two-sided flips and continuation dependence also appear when a same-bit-width checkpoint replaces Q's action (Step 1), and outcomes also change under one key-order change that leaves the tool operation identical (Step 4; exploratory). Their presence alone therefore does not show that a decision needs B. The comparison that isolates B's extra action value, at common q8 states, resolves neither an advantage nor equivalence (Step 3). Sensitivity to an action, the value higher precision adds at a state, and the gain of a given upgrade need separate measurements. % nocheck: step labels
