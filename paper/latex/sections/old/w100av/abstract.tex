\begin{abstract}
Evaluations of low-precision agents usually measure how far the quantized model drifts from its BF16 reference. A deployment that can fall back to BF16 needs the task value of a specific upgrade under the policy that runs afterwards. We restore a decision state exactly, replace the current action, the subsequent controller, or both with BF16, count the rescues and damages of each option, and read them against a same-precision substitute, a meaning-preserving representation change and a hindsight oracle. On Qwen3 agents under simulated quantization in \tautwo{}, replacing a quantized agent's first tool-structure-divergent action changes 15.5--20.9\% of outcomes in both directions; the pooled net effect is $+0.7$ points (new-task 95\% interval [$-2.1$, $+3.5$]). On held-out telecom tasks under a pre-registered protocol, the net effect is $-4.6$ points (crossed 90\% interval [$-7.2$, $-2.0$]); the frozen readings had only positive-gain and small-effect categories, so the protocol classifies it as inconclusive. Action-only and whole-takeover evaluations miss different rescues. A same-precision substitute also produces substantial two-sided turnover, so outcome sensitivity is not by itself evidence that more bits are needed.
