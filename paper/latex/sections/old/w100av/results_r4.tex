\section{How Long and Where Do the Consequences Hold?}
\label{sec:scope}
\label{sec:duration}

This section is exploratory; key-order and takeover analysis code was frozen before outcomes were read.

\paragraph{Representation change.} On 300 verified tool-call states of q8 GPTQ-W4 (41 tasks; airline 187, retail 113), we reverse the order of the top-level argument keys in Q's action. The parsed call and its effects are identical; only the next tokens the agent reads change. This changes the outcome in 6.7\% of these states ([0.8, 14.4]), against 9.0\% [2.9, 18.2] for B's action on the same states (Table~\ref{tab:refs}); the difference, $-2.3$\pp{} [$-8.4$, $+2.9$], is not resolved, and we claim no equivalence. Some outcome changes therefore arise without any change to the tool operation. The result covers only these states and this one change, not free-text or other representation changes (Appendix~\ref{app:keyorder}). % src: analysis/fork/out/keyorder_20261005T204349Z.md; analysis/fork/keyorder/eligibility_v1.md; docs/insights/KEYORDER_PERTURB_PROTOCOL.md (intervals: widest of block and crossed bootstrap on the pooled ratio)

\paragraph{Ordinary states and the user simulator.} At ordinary (Bank U) states, turnover is lower (W4 configurations, U1 and U2B: 4.7--9.0\%) and the net gain covers zero. Most outcome changes there come from differences in text. We could not confirm their labels under a second user simulator (one control exposed replies to sibling arms; Appendix~\ref{app:ordinary}), so we do not report them as a property of the action. % src: analysis/fork/out/bank_u_f01_f02_f03_20261002T003037Z.md (§2); analysis/fork/out/simctrl_20261001T212742Z.md
On the q8 U2B panel, $G$ is resolved in no configuration, while fixed-pool $H$ or $F$ exceeds zero in several (Appendix~\ref{app:panels}). % src: analysis/fork/out/newmethod_q8_20261004T051538Z.md (τ² U2B all states: G, H, F with crossed columns)

\paragraph{Takeover duration.} On 255 q8 U2B states of the \S\ref{sec:r4} panel ($n_{\mathrm{blk}}=3$), Q's action is followed by $L$ BF16 decisions and then by Q again. SpinQuant-W4A4 was chosen \emph{after} its sustained-takeover value on this panel ($H=+11.8$\pp{}) was seen, and the sustained arm reuses that endpoint, so its results are conditional on that selection; the intervals are not adjusted for this configuration selection. Against Q's own continuation, a one-decision takeover there shows no detectable net gain ($0.0$, crossed [$-3.5$, $+3.5$]). Four decisions gain $+6.3$\pp{}: the registered block-$t$ analysis supports this all-state gain in the selected configuration ([$+0.2$, $+12.4$], 2 df), the crossed interval does not confirm it ([0.0, $+12.2$]), and an all-state gain alone does not show that value is kept after handback to Q (frozen reading; Appendix~\ref{app:takeover}). Four decisions fall $5.5$\pp{} short of sustained takeover ($+11.8$; paired difference block-$t$ [3.8, 7.2], crossed [0.8, 10.6]). % src: analysis/fork/out/takeover_20261005T1604Z.md (Reading); analysis/fork/out/takeover_20261005T1604Z.json (cells.spinquant_w4a4.primary.all_states_pp: t_ci95, crossed_ci95); docs/insights/TAKEOVER_WINDOW_PROTOCOL.md (§8 primary interval; §9; Amendment 3)
Four-decision windows handed control back at 66\% of states; the rest ended inside the window, so they cannot show that four steps suffice. Under GPTQ-W4 the continuation value itself is small ($+0.8$, crossed [$-5.9$, $+7.5$]) and no window effect is resolved (Appendix~\ref{app:takeover}). In the selected configuration takeover value depends on its length \citep[cf.\ handoff costs,][]{ganz2026handoff}; GPTQ-W4 does not resolve whether this generalises. % src: analysis/fork/out/takeover_20261005T1604Z.md (Handback per window: spinquant_w4a4 Q4 buckets 169/255); analysis/fork/out/takeover_20261005T1604Z.json (cells.gptq_w4_d1.primary.all_states_pp.V_Qinf); derived: 66=100*169/255
